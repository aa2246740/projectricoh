# 用原厂菜单验证配方保存

历史实验，当前请执行 [A12 50mm 协作与操作清单](A12_50_COLLABORATION.md)。当前首轮只用 50mm、研究卡同一槽和 A0/A1/B/A2，不执行下文双模块、Box、MY 拨盘或跨模块实验。

这次实验只用 GXR 的正常菜单。它回答两个问题：My Settings 是否独立保存自定义颜色参数，SD 卡记录的哪些字节跟颜色参数一起改变。

暂按 A12 28mm 与 A12 50mm 两款分别测试。先记录机身及当前模块版本，记录 Start Settings Readout 是 Body 还是 Camera Unit。机身与模块低于 1.50 时，先报告版本，本实验的 Card 步骤暂不适用。版本和 Card 菜单都要实际核对；官方页面对 A12 50mm 在 1.50 的支持有一处矩阵冲突，见配方报告。本计划不包含升级或刷写步骤。

## A/B 交叉实验

先拍照记录现有 Setting 1、Setting 2 的全部 13 个字段，以及当前白平衡、曝光和按钮设置，实验后按记录恢复。Box 实验只用两个明确未使用的槽；下文 Box 1/2 是示例槽号。没有空 Box 时先只做研究用空卡的 Card 1/2 实验，Box 结果标为未执行，保留原有记录。

调用实验优先使用未使用的 MY 拨盘位置，下文 MY1 是示例。三个 MY 位置都已使用时，先把原 MY1 通过原厂菜单保存到研究卡的 Card 6，并记录其原 Box 关联。完成后恢复原 MY1、Box 关联和记录的原始颜色值；Card 6 保留为实验前备份。

1. 两款 A12 各用一张独立的研究卡，在相机中格式化。先在 A12 28mm 完整执行步骤 2 至 5，再在 A12 50mm 独立创建并完整执行步骤 2 至 5。保持同一静物和固定照明，在 P 模式设 My Settings WB Comp. 为 On，把 ISO、白平衡、曝光补偿等设为相同值。记录当前值，方便实验后恢复。
2. 在 Setting 1 中建立 A：全局鲜艳度设为低端，红色色相设为低端。只用机内允许的值。记录全部 13 个颜色字段的显示值，拍摄参考 JPEG。把当前状态保存到 Box 1、Card 1。Box 命名为 `COLOR-A`；Card 若实际菜单允许命名则命名，否则记录槽号与界面原样文本。
3. 仍使用 Setting 1，建立 B：只把鲜艳度和红色色相改为高端。其余值保持一致。拍摄参考 JPEG，保存到 Box 2、Card 2。Box 命名为 `COLOR-B`；Card 的命名同样以实际菜单为准。
4. 使用 Recall My Settings 把 Box 1 分配给 MY1。转到 MY1，核对全部 13 个颜色字段，拍摄 JPEG。切走再调用 Box 2。记录两个记录是否恢复不同的参数。
5. 关机重启，重复步骤 4。再用 Card 1、Card 2 重复。不要仅根据名称或屏幕风格判定，须记录参数值和 JPEG。
6. 两款各自完成创建与保存实验后，另做双向跨模块实验。先在 A12 50mm 调用 A12 28mm 创建的 Card 记录，再在 A12 28mm 调用 A12 50mm 创建的记录。每次记录 Start Settings Readout、13 个字段、JPEG 和任何错误提示。跨模块调用结果与本模块创建结果分开保存。

| 结果 | 下一步 |
|---|---|
| Box 和 Card 都恢复各自的 A/B 颜色参数 | 先研究扩展配方库的索引和调用方式。保留原厂颜色处理程序。 |
| Box/Card 都只恢复同一个 Setting 1 参数 | 需要在新增配方加载时显式恢复颜色参数数组。 |
| Box 与 Card 或两个 A12 结果不同 | 分别查记录布局和模块参数同步，不能共用一份未经验证的补丁。 |

## SD 卡记录的单变量捕获

通过正常菜单把 My Settings 保存到 SD 卡后，关机再用读卡器复制文件到电脑。不要在相机运行或写卡时取卡。使用空的研究用卡，并把照片留在原卡。

先完整查看保存前后的文件目录，包含隐藏文件，确定原厂实际创建的文件路径。当前研究尚未确认路径，不预填 `.DAT` 文件名。每次只在相机菜单中改一项，再导出。保持同一 Card 槽、同一名称、同一模块和固件。

按以下次序捕获：基线 A0、完全相同设置再次保存 A1、只改鲜艳度 B、恢复基线 A2、只改红色色相 C。A0/A1 用来识别计数器或时间等不稳定字节。A0/A2 用来检查恢复是否可重复。

每个捕获目录保存原厂实际生成的设置文件、目录清单、模块/版本、菜单值和 JPEG。保留原始文件不改动。两款 A12 分别执行整套捕获，每次只改一个字段，并分别覆盖全部 13 个颜色字段。只把已经确定的设置文件交给比较工具。

```sh
python3 scripts/diff_settings.py captures/A0/实际设置文件 captures/A1/实际设置文件 --output artifacts/capture-diff-A0-A1.json
python3 scripts/diff_settings.py captures/A0/实际设置文件 captures/B/实际设置文件 --output artifacts/capture-diff-A0-B.json
python3 scripts/diff_settings.py captures/A0/实际设置文件 captures/A2/实际设置文件 --output artifacts/capture-diff-A0-A2.json
```

比较工具只报告变化字节及 SHA-256，不判断字段意义，也不生成可写回相机的文件。固件里的 PARAM.DAT、CONFIG.TST、BKIZRAM.DAT 等名字不等于用户配方文件；本实验只采集原厂 My Settings 菜单自己生成的文件。

## 完成标准

两款 A12 各有本模块创建的记录：版本、A/B 的全部 13 个实际参数、关机重启后的参数、Box/Card 结果和对应 JPEG。Box 因没有空槽而跳过时，明确标为未执行，不能据 Card 结果声称 Box 通过。双向跨模块调用有另外的记录。只有原厂文件样本、没有参数和 JPEG 对照时，数据结构分析仍属于候选。
