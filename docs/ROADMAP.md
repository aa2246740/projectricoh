# 路线图：把 GXR 改成现代 GR

日期：2026-10-13。用户目标：GXR 的风格与操作接近现代 GR（GR III 的 Image Control 一类）。机身＋A12 50mm 先行。

## 能改与不能改

固件能改的是软件行为：风格配方、菜单入口、图像参数、文件内容。传感器、防抖、触摸屏、对焦马达、蓝牙这类硬件能力不在本项目范围内。

## 产品方向

- 配方独立于曝光模式，P/A/S/M 都能用。不放进场景模式，场景模式下 Image Settings 不可用、曝光全自动（机身手册第 59–60 页）。
- 一键入口：ADJ 拨杆弹出配方列表，配方平铺可选。原厂已支持把 Image Settings 挂到 ADJ 拨杆（手册第 134 页）。
- 每次拍摄保存配方 JPEG＋原厂 DNG。

## 为什么先做阶段 0

中文补丁只修改 `ilaunch3`，作者报告有特定真机刷写成功，并以官方 1.51 包恢复。这是同类改动的公开先例，但不能保证适用于每台机身，也不能说明模块固件改动的风险。[中文补丁说明](../sources/gxr-language-patch/README.md)

阶段 0 用最小的文字改动，在你的相机上走通"我们构建 → 刷入 → 开机 → 刷回官方"全链路。这一步通过之后，再投入阶段 1 的功能集成。阶段 1 尽量只改机身，保持在同一风险类型内。阶段 2 起需要修改模块固件，目前没有公开先例，风险要单独评估。

刷写失败时的恢复能力仍未在你的设备上验证。详见 [RAW 与风险说明](A12_50_RAW_AND_RISK.md)。

参数优先级依据 [GR 参考调研](../research/gr_reference/REPORT.md)：59 条流行配方中近一半以正片/负片为底，GR III 配方几乎都用到清晰度和高光/阴影对比。机身到模块的参数通路见 [隐藏处理能力调查](../research/hidden_processing/REPORT.md)，字段编码见 [字段报告](../research/field_mapping/REPORT.md)，DNG 结构见 [DNG 报告](../research/dng_structure/REPORT.md)，曲线见 [对比度曲线报告](../research/contrast_curve/REPORT.md)。
