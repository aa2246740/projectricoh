# GXR 配方菜单使用指南

适用：理光 GXR 机身（屏幕上的版本号仍显示 1.51）。
镜头单元：GR LENS A12 50mm、A12 28mm、GXR MOUNT A12 三种都支持。

> **这是非官方修改。** 刷写固件有风险，请自行判断。
> 电量不足时不要更新。
>
> 本文里的新界面操作，还需要在相机上逐项核对（按键反应、屏幕字样、拍完后的画面）。标注「待确认」的内容，目前还没有核实。

---

## 1. 这是什么、能做什么

这是给 GXR 加的一套**画面配方**。

- 配方 = 一种画面风格。你选一个，取景和拍出来的照片就会变成那个风格。
- 你还可以微调配方，比如让画面更反差、或更鲜艳。
- 相机原厂的样子叫「04 标准」。开机后，相机默认是它。

八个配方：

| 编号 | 名称 | 风格 |
|---|---|---|
| 01 | GRPos | 理光 GR IV 正片风格 |
| 02 | GRNeg | 理光 GR IV 负片风格 |
| 03 | HC BW | 高反差黑白 |
| 04 | Std | 相机原厂标准（开机默认） |
| 05 | F-CC | 富士 Classic Chrome 风格 |
| 06 | F-CN | 富士 Classic Neg. 风格 |
| 07 | L-Chr | 徕卡 Chrome 风格 |
| 08 | L-Viv | 徕卡 Vivid 风格 |

## 2. 第一次安装

安装分两种，按需要选：

- **刷机身**：第一次安装，或者要恢复时才做。
- **只换配方文件**：不用刷机，见 2.3。

### 2.1 准备

- 理光 GXR，电池充满。
- 一张存储卡。
- 包里 `SD_ROOT` 文件夹下的全部文件（包的名称和版本：待确认）。
- **A12 50mm 镜头单元。** 请用它来刷机。
  用其它镜头刷过之后，50mm 曾经开不了机。

### 2.2 刷机身（只做一次）

**第 1 步：复制文件到卡上**
- 你会看到：卡的最外层（不是文件夹里面）有包里的全部文件。
- 按：把 `SD_ROOT` 里的全部文件复制到存储卡的根目录。

**第 2 步：装上镜头和卡**
- 按：把卡插进相机，装上 A12 50mm 镜头单元。
- 确认电池是满的。

**第 3 步：开机进入更新**
- 按：按住 `+` 键和回放键，同时开机。
- 你会看到：相机进入固件更新画面（具体样子：待确认）。

**第 4 步：等它完成**
- 按：等更新结束。更新中不要关机，不要取出电池。
- 你会看到：更新完成后，相机可以正常使用。

**第 5 步：确认**
- 存储卡保持插在相机里。
- 开机后，按第 3 节的方法选一个配方，看画面是否变化。

### 2.3 以后只换配方程序（不用刷机）

- 按：把卡上的 `GXRCE.DAT` 换成新的一份。
- 卡一直插在相机里。
- 按：换好后，**关机再开**。配方是开机时从卡上读取的，不关机不会生效。

### 2.4 三种镜头

三个镜头单元都能用配方菜单。

- MOUNT 的配方是用一支测试镜头校准的。换成不同的 M 口镜头，效果可能有差异（待确认）。

## 3. 日常使用：选配方、微调、关闭

### 3.1 选配方

**第 1 步：打开配方列表**
- 你会看到：屏幕上出现八个配方，每行一个。
- 按：推 **ADJ 拨杆**。

**第 2 步：上下移动光标**
- 你会看到：画面马上变成光标所在配方的效果。
- 光标移到最上或最下会停住，不会绕回来。

**第 3 步：关闭列表**
- 你会看到：列表消失，画面保持你刚才看到的效果。
- 按：**OK**、**ADJ** 或**轻按快门一半**，三个键都可以。

> **注意：** 关闭时光标停在哪个配方，就用哪个配方。
> 没有「取消」。要撤销，见 3.3。

### 3.2 微调

**第 1 步：打开配方卡**
- 你会看到：光标所在配方的卡。第一行是配方名，名字前面有 `<`。下面是几项数值，两项一行。
- 按：光标停在要调的配方上，按 **DISP**。

**第 2 步：进入逐项列表**
- 你会看到：每项数值一行。
- 按：光标停在「两项一行」的那一行，按 **DISP**。

**第 3 步：进入数值页**
- 你会看到：一个项目的数值，光标在它当前的数值上。
- 按：光标移到要调的项目，按 **DISP**。

**第 4 步：调数值**
- 按：**上键**加一档，**下键**减一档。
- 你会看到：画面马上跟着变。
- 数值范围是 **−5 到 +5**，0 是配方原样。

**第 5 步：返回**
- 按：数值页按 **DISP**，回到逐项列表。
- 按：在第一行的 `<` 上按 **DISP**，回到上一层。

**第 6 步：关闭**
- 按：**OK**、**ADJ** 或**轻按快门一半**。
- 你会看到：列表消失，画面保持调好的效果。

| 项目 | 意思 | 只在哪些配方里 |
|---|---|---|
| Cont | 对比：亮和暗的差距 | 全部 |
| High | 高光：亮的部分 | 全部 |
| Shad | 阴影：暗的部分 | 全部 |
| Satu | 饱和度：颜色鲜不鲜艳 | 彩色配方（黑白 03 没有） |

### 3.3 撤销微调（全部归零）

1. 你会看到：在配方卡的 **Default** 那一行。
2. 按：在 **Default** 行按 **DISP**。
   - 第一次：屏幕出现 `Sure?`。这时还没有改动。
   - 再按一次 **DISP**：当前配方的所有数值回到 0。
3. 注意：如果中间按了上下键，`Sure?` 会取消，要重新来。

也可以逐项把数值调回 0。

### 3.4 关机之后

- 关机再开，画面回到 **04 标准**。
- 你调过的数值，关机后都不保留。
- 相机不记得上次用的配方，开机后要重新选一次。

## 4. 屏幕上的符号是什么意思

| 屏幕上的样子 | 意思 | 例子 |
|---|---|---|
| `>` | 相机**已经生效**的配方。关闭列表后留下的那个。 | `>4 Std` |
| `*` | 这个配方这次开机后**调过数值**。关机后消失。 | `>5*F-CC` |
| `!` | 数值**已到头**（最大或最小），不能再往那个方向调。 | `Cont! +5` |
| `<` | **返回上一层**。在这一行按 **DISP**。 | `<5 F-CC` |
| `Sure?` | **等你确认**。再按一次 **DISP** 才会执行。 | `Sure?` |
| `ERR` 加四个字符 | 出错了。见第 6 节。 | `ERR 0ABC` |
| ` DISP:Tw` | 列表最后一行，是提示。在这里按 **DISP**，可以看当前配方的卡。 | ` DISP:Tw` |
| `MyRec` | 我的配方。见第 5 节。 | ` MyRec` |

数值的写法：
- `Cont   0`：0 没有正负号。
- `Cont  +2`：正数前面有 `+`。
- `Cont  -2`：负数前面有 `-`。

## 5. 我的配方（MyRec）

### 5.1 这是什么

- **MyRec** 是「我的配方」。它保存着你在电脑上调好的配方条目，放在卡里的配方文件中。
- 相机上**只能看、能试**。不能在相机里存、复制或删除条目。
- 条目要用 Mac 工具生成（见 5.3）。

### 5.2 在相机上看

**第 1 步：进入 MyRec**
- 你会看到：列表里的 ` MyRec` 行。
- 按：移到 MyRec，按 **DISP**。

**第 2 步：看分组**
- 你会看到：每个配方一组。组名后面的数字是条目数。
  例：`FCC   1` 表示 F-CC 这一组有 1 个条目。
- 组里没有条目时，显示 `None`。在 `None` 这一行按 **DISP** 没有反应，属于正常。

**第 3 步：进入一组，看条目**
- 按：移到组上，按 **DISP**。
- 你会看到：条目列表。**最新的在最上面。**

**第 4 步：预览条目**
- 你会看到：光标移到条目上，画面马上变成它的效果。
- 注意：只进入分组，不会改变画面。移到条目上，画面才会变。

**第 5 步：打开条目的卡**
- 按：在条目上按 **DISP**。
- 你会看到：条目的配方卡，可以看，也可以微调。

> **注意：** 在条目上做的微调，只在这次开机时有效。关机后恢复文件里的原值。

### 5.3 在 Mac 上生成条目（需要终端，会用的人才做）

**前提：** 用 Mac 自带的 `python3`，不用另外安装。

**第 1 步：检查原来的配方文件**
从项目根目录运行：

```sh
/usr/bin/python3 -I -B firmware/engine_v46_ui/user_entries.py check firmware/package_v36_g124/SD_ROOT/GXRCE.DAT
```

**第 2 步：写一个清单文件**

清单每行写一个条目：底子编号，然后是项目和数值。底子编号 1–8 对应 01–08 配方。

```text
5 Cont=1 High=-1 Shad=2 Satu=-2
```

意思是：F-CC（05）配方，对比 +1，高光 −1，阴影 +2，饱和度 −2。没写的项目为 0。

**第 3 步：生成新文件**

```sh
/usr/bin/python3 -I -B firmware/engine_v46_ui/user_entries.py build firmware/package_v36_g124/SD_ROOT/GXRCE.DAT --manifest 你的清单.txt --output 新文件路径/GXRCE.DAT
```

- 工具不会改动原文件。
- 输出必须是还不存在的新文件。

**第 4 步：换进卡里**
1. 先把卡上原来的 `GXRCE.DAT` 另存一份备份。
2. 把新生成的 `GXRCE.DAT` 复制到卡的根目录，覆盖原文件。
3. 卡保持插在相机里，**关机再开**。

**生成时的规则：**

- 每个配方的四项（Cont、High、Shad、Satu）只能在 **−5 到 +5** 之间。超出的会被拒绝。
- 黑白配方（03）没有饱和度，不能设 Satu。
- 每个文件最多 **32 个条目**。
- 生成的文件要和机身上装的版本匹配（待确认）。

## 6. 常见问题与恢复

### 6.1 常见问题

**按 ADJ 没有出现配方列表。**
- 确认存储卡插在相机里。
- 配方是开机时读取的。如果开机后才插卡、或中途换过卡，**关机再开**。

**屏幕上出现 `ERR` 加四个字符，例如 `ERR 0ABC`。**
- 按：**关机再开**。开机后是 04 标准。
- 你会看到：`ERR` 的画面不代表图像已经恢复正常，所以一定要关机再开。
- 如果反复出现，记下屏幕上的字符，告诉项目维护者。

**列表只有相机原厂的选项，没有配方名。**
- 按：先**关机再开**，再试一次（待确认）。

**半按快门后，列表又出现了，行数或内容不对。**
- 这个问题在 v3.7 机身上做了修复。实拍验证还在进行（待确认）。

**28mm 开机后第一次打开，只看到原厂选项。**
- 旧版本曾出现过：拍完后第一次打开只显示原厂的 7 行。
- 新版本是否还会出现，待确认。
- 先不要在原厂选项里上下移动（这会改动相机自己的图像设置）。直接退出，再打开一次。

**微调后关机，数值没有了。**
- 正常。当前版本不保存你的微调。

**MENU 里的「图像设置」还是原厂选项。**
- 正常。配方菜单在按 ADJ 时打开，和 MENU 里的选项不是同一个。

### 6.2 恢复

如果相机出了问题，可以用下面两种方式恢复。

**方式一：用备用卡刷回**

- 用备用卡（标签为 Stage2l 版）。
- 步骤与 2.2 相同：装上 A12 50mm，按住 `+` 和回放键开机，等待完成。

**方式二：刷回理光官方 1.51 固件**

- 把理光官方 GXR 1.51 固件文件复制到存储卡上（文件的获取位置：待确认）。
- 装上 A12 50mm。
- 按住 `+` 和回放键开机，等待完成。

> 更新时电量要充足。电量不足时不要更新。

## 7. 即将推出

以下功能**还没有上机**，效果和操作都可能调整。

### 7.1 新旋钮版：更多可调项目

| 名称 | 作用 | 范围 | 状态 |
|---|---|---|---|
| Warm 冷暖 | 整体偏暖（发黄）或偏冷（发蓝） | −9 到 +9 | 未上机 |
| Tint 品绿 | 正向偏品红，负向偏绿 | −9 到 +9 | 未上机 |
| Splt 分离色调 | 高光和阴影分别加上不同的颜色 | −9 到 +9 | 未上机 |
| Fade 褪色 | 让画面发淡，像褪色的老照片（只能往加的方向） | 0 到 +9 | 未上机 |
| Filt 黑白滤镜 | 黑白配方里，模拟镜头前加了色彩滤镜的效果 | −9 到 +9 | 未上机（只在 03） |
| Amt 强度 | 整个配方的强弱。100% 是配方原样，0% 是相机原厂的 04 标准 | 0% 到 150% | 未上机 |

- 新旋钮版的每项可调到 ±9，比现在的 ±5 更细。
- 冷暖和品绿的方向，要上机后确认。

### 7.2 在相机里保存我的配方

- 目前不能在相机里保存配方。
- 等机身更新后再做。
