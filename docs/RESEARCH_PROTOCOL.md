# GXR 色彩配方研究协议

目标是让 Ricoh GXR 保存和调用更多用户色彩配方。当前首版集中 A12 50mm，目标为16个列表选择的独立配方，并同时保留配方 JPEG 与 DNG RAW，详情见 A12_50_SCOPE.md。用户已在 2026-10-12 授权按此目标开始本地固件开发。授权覆盖研究、下载公开资料、项目内工具安装、本地源码和机器码构建、静态分析及桌面验证；本阶段没有相机访问，不刷写或写入相机配置、校准数据。

## 证据要求

- 技术事实优先使用 Ricoh 官方手册、官方固件、项目源代码与可重跑结果。论坛只能提供线索。
- 每项结论标明：官方文档已确认、上游报告、静态分析已确认、推断、待验证。
- 记录来源 URL、日期、仓库 commit、文件 SHA-256、固件文件名和分析命令。代码定位使用文件路径及行号，二进制定位同时记录文件偏移和运行地址；没有映射证据时不把二者混用。
- 区分 Image Settings 的 Setting 1/2、My Settings、机身保存槽、SD 卡保存槽和完整色彩配方。不得把新增菜单项当成持久化功能已经实现。
- 首版先给出 GXR 机身与 A12 50mm 的证据，其他模块留作后续兼容研究。模块未确认时不宣称通用。
- 中文语言解锁能证明的范围是其实际修改路径。它不能独自证明存在空闲 RAM、可用代码空间、可扩展设置结构或安全恢复能力。
- 禁止上传官方二进制、私人照片、序列号、个人配置、凭据。禁止运行下载的相机固件、未知安装脚本或相机刷写工具。允许执行本项目编写的宿主参考程序及汇编器、链接器，用于离线验证；宿主测试不证明相机行为。工具安装先读入口与依赖，使用项目内目录。
- 遵守用户的 Codex 原生 CUA、T3 浏览器、Playwright pin 和 Apple Container 政策。无需浏览器交互时可使用只读 web 搜索和公开 API。

## 每份 worker 报告

先写结论，再给证据表、可实施路径、未知项和最小下一步实验。每个事实引用支持它的直接来源。若编写分析脚本，必须执行并记录输出。报告不得声称已经实现新增配方，也不得把桌面工具测试当成相机验证。

最终验收应包含：16个配方的列表选择、编辑、保存、重启保留、覆盖/删除、SD 卡缺失或损坏行为、同一次拍摄得到带配方的 JPEG 与完整 DNG、与现有 Setting 1/2 及 My Settings 的一致性。研究报告列出这些验收，不在无真机证据时宣称通过。
