# A12 50mm 配方核心：已知接口与未知接口

日期：2026-10-12。用户授权按 16 条命名列表配方、同次 JPEG+DNG 的目标开发；相机尚不在身边。本轮先实现可在宿主测试的核心和代码生成环境，不能把它标成可刷固件。

## 用户调用与数据流

菜单选择某条配方，读取它的颜色参数，仅更新 Image Settings，再由原厂拍摄流程保存 JPEG 与 DNG。名称和颜色参数可分别编辑并保存。切换配方不能恢复完整 My Settings，因为现有记录包含曝光、对焦、画质等拍摄状态。

1. 现有 My Settings 保存入口是机身 `ilaunch3` VMA `0x2011D728`，加载入口是 `0x2011E350`。
2. 固定 1024 字节记录包含 288 字节负载，现有槽号限定 1 至 6。文件 I/O 和完整性算法已有静态证据；完整恢复会更新大量全局拍摄设置。
3. 原厂 Image Settings 每套有 13 个参数，Setting 1/2 共有 26 项。每项对应哪个 RAM 地址、记录字节以及模块命令尚未确认。
4. 原厂 RAW 模式创建 DNG 与 JPEG；图像设定只作用于 JPEG。新增菜单不能改 Picture Quality，且必须保留原厂拍摄和保存调用链。
5. 菜单 hook、可用代码空间、调用 ABI、原厂参数实际取值范围、DNG 可达调用链和恢复入口尚未验证。

主证据为 [原厂记录分析](../../research/a12_50_firmware/REPORT.md)、[当前目标](../../docs/A12_50_SCOPE.md)和 [RAW/风险](../../docs/A12_50_RAW_AND_RISK.md)。

## 核心开发边界

- 配方记录是新设计，不能冒充原厂 `.IFO` 或可刷的 `ilaunch3`。
- 核心可接受颜色参数的字节表示；这些字节在没有相机字段映射前只能是合成数据，不应发布为已校准胶片配方。
- 核心必须支持 16 个独立槽及非法/截断记录检查；存储 codec 与当前相机文件接口解耦，不能猜测 rename、fsync、原子替换等原厂能力。
- 核心 API 只返回颜色参数或只写明确提供的颜色目标。不能拿到整块相机配置对象，避免覆盖画质、曝光、对焦与按钮状态。
- 宿主 C 测试验证数据和 API；GNU M32R 汇编/链接向量验证生成工具。两者均不代表核心已经注入固件或在相机执行。

## 升级与控制边界

官方升级手册确认 SD 卡作为升级介质。USB 或读卡器仅提供文件复制方法，相机仍需按键确认更新。本项目目前没有已验证的 USB 遥控接口。

上游研究的 MONI/BKUP、私有 USB、串行 shell 等发现是线索。上游设备的实机枚举不是本项目的设备验证；存在这些结构不能证明坏主程序仍可救援。
