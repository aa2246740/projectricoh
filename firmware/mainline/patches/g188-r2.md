# g188-r2

`g188-r2.patch` is the public difference from the g185 engine tree to `research/boot_copyright_g188_r2/local/engine`. It includes the public part of `eng_core.c`: catalogue-identity migration and the copyright read-back. The identity bytes and the camera-setting offsets are not in the patch. `prepare_local.py --profile g188-r2` writes them into `local/engine/.../eng_core_private.h`. Prepare that profile before the build:

```sh
GXR_PRIVATE_ROOT=<private root> \
  nice -n 15 /usr/bin/python3 -I -B firmware/mainline/prepare_local.py --profile g188-r2
```

Apply the patch from `firmware/mainline`, then build with the g188 profile. The profile writes generation 188 and keeps the g188 `-frandom-seed` paths. Receipt paths are relative to the public tree or the private root. The compile macros stay `G175_BOOT` and `G175_DIAG_SILENT`, which is what that build recorded.

```sh
patch -p1 < patches/g188-r2.patch
nice -n 15 /usr/bin/python3 -I -B firmware/mainline/build.py --profile g188-r2 \
  --verify-against "$GXR_PRIVATE_ROOT/research/boot_copyright_g188_r2/local/model-r2d/GXRCE.DAT"
```

`adapter.c` in the patched tree carries the version string that is in the g188 source. Do not edit it to spell another generation. The DAT generation is the header field written by `--profile g188-r2`.
