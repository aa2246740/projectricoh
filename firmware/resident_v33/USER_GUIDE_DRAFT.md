# A4 操作草稿

当前候选还没有通过栈门槛，也没有上机验收。本页只说明已在主机夹具中验证的操作。

1. 打开 Image ADJ 后，列表显示 01 到 16。上下选择配方，OK 确认；首次打开直接按 OK 也会应用当前行。
2. 在配方列表按 Fn2，进入该配方的对比页。11 行分别是 -5 到 +5，光标停在当前值。
3. 上下移动就预览草稿。再按 Fn2，依次看饱和、高光、阴影，再回到对比。冷暖和色调暂不显示。
4. 按 OK，把草稿保存到 GXTS，再关页面。按 MENU，恢复进入面板前的值，再关页面。
5. 明确的保存失败会撤回草稿；写入结果不确定或会话校验失败时，扩展停用到重启。旧分配保留，不冒险释放。
