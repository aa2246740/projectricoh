# g138 复审运行器

本目录只承载复审脚本、模型夹具和证据。产品源码、实现报告、v3.8 机身、g137 和 g138 包均由系统围栏保护，不允许测试进程写入。未连接或读取实体测试卡。

`offline.sb` 允许写本目录和指定 Scratch，拒绝网络和其他文件写入。`scope_check.py` 在启动测试前实测允许路径、拒绝路径和网络拒绝。冻结输入清单是 `evidence/inputs-before.json`。

## 读取修改

`legacy/legacy_call.py`、`legacy/users_gxui.py`、`fixture.py` 从实现者的 g138 包装器复制到复审目录。源文件哈希与初始重定位记录在 `evidence/wrapper-provenance.json`。底层旧测试文件保持只读。

| 修改 | 目的和限制 |
| --- | --- |
| 包、ELF、generation、长度及 SHA | 绑定最终 g138 DAT 和 canonical resident_v38。用户夹具另有 SHA，不把夹具称为原始发布 DAT。 |
| 输出目录和临时目录 | 每个矩阵组使用独立 job 目录，外层退出回执写 `evidence/receipts/`，避免与内层测试结果同名。后续运行器也强制最终子进程环境的 TMPDIR 位于指定 Scratch。直接模型补测的解码缓存按 job 分开，避免两路读取尚未写完的同名列表。 |
| 原厂锁初始化 | 原模型的 0/0 没有运行原厂锁初始化。将空闲状态绑定为计数 −1、ID 55，符合本地原厂初始化和锁参考证据。不能借此声称跑过真实开机。 |
| S 正常启动夹具 | 实现者还改了模式、WB、来源、扩展版本和记录尾部。这比“只初始化锁”范围更大，主矩阵以此验证普通启动。它消除了冷启动时的原有 op 2 写入需要，必须另外覆盖非正常 S 和锁忙。`focused_review.py`、`lock_trace.py` 和相关 persist 子项承担这些检查。 |
| C 的四个文本常量 | 数值页端点的两个期望、卡片和逐项页的两个期望去掉端点 `!`。数值、光标、夹紧、完整参数和通信断言均保留。 |
| g137 列表行为 | 保留此前已核对的 L1 循环、返回光标和条目循环读取。补齐原包装器遗漏的 transitions 填充行、空条目 DOWN 循环，以及 locked 页绘制文本中的分隔线。分隔线是 g137 已有约定，不是本版新增行为。 |
| 旧用户工具 | 沿用 g137 复审的当前格式桥接。32 条记录往返和无效输入检查仍由旧工具执行，不修改正式引擎树。 |

分隔线修正只作用于指定文件、行号和旧期望，且重复应用不会再次改变结果。没有删除产品断言，也没有把错误返回码改为 0。

旧 `project_boundary.py` 调用已删除的 `uv_levels`，旧 `label_acceptance.py` 假设旧的三项黑白页面。它们在 81 组内照常执行并保留原退出码。当前范围检查和当前页面检查另列为替代证据，不改写原组 PASS。

## 进程与回执

`run_regressions.py` 用两个信号量槽位等待子进程退出，不使用 sleep 轮询。fork 用例由其父进程逐个 wait，预检查也逐个执行，因此同时最多两个进程实际执行测试。81 组的外层和旧运行器内层均设 10,800 秒，没有总时间盒。

旧包装器首轮把临时环境重新设到了复审目录内。它没有越过系统写入围栏；本轮随后补了环境约束，并将最初 safety 组加入最终复跑队列。早期预检查失败也曾阻断三个矩阵组，最终队列会完整重跑这些组。原始失败回执保留。

新功能全套最初作为附加检查启动，六个子项完成后主动停止，把资源交给要求的 81 组。停止回执为 −15；不能把该附加整组记为通过。后续针对锁、异常首开、记录重试、用户标题和端点的检查各有独立证据。

`make_tables.py` 同时核对外层 OS 回执、内层整组结果及逐案 wait 状态。observations 为 0 不能替代这些读取。当前矩阵和最终复跑的回执均保存在 `REGRESSIONS.json` 的 attempts 中。

## 字节和现场证据

派生汇编、模型行内容、ELF、DAT 及重建产物只放在本机 `local/`。报告只列地址、长度、比较结果和哈希，不粘贴理光固件字节。

M32R 指令检查仍使用设备与图形叶函数模型。主机 C 比较、模型首开和实体关机持久性属于不同证据层。当前普通模式、MY、参数来源和复位事件是否满足真实启动约定，不能由一组同值参数代替。

静态差异检查的首轮仅比较 candidate，漏掉提供文件末尾的 resident/abi.h 差异；前820行相同，缺项21行。修正比较范围为 candidate 加 resident/abi.h 后，使用新 job 名重跑，原失败回执及 candidate-only 差异保留。这是复审准备范围错误，不是产品漂移证据。

指令数学检查的首轮在定位镜像时失败：g138 新增的非零初始化变量 t_seen 位于加载镜像内，H01 后已从初始化值变为 2。旧检查器只容许 relocation 改变，因而拒绝该 RAM。复审只在身份比较副本中归一化 ELF 明确标识的 4 B t_seen，其余字节与所有 relocation 仍严格核对，执行 RAM 不作修改。每个单元的 identity-binding.json 记录原始差异、符号位置和归一化 SHA。使用新 job 名重跑，首轮失败保留。
