### 身份、空间和最终 Looks 字节

原 `identity_compare.py` 对 c0 和 g151 两个参考分别运行。两组整机身比较都只有 34 B 改变，全部位于身份区 `[0x98a4,0x98d4)` 和校验字。可分配节、root、pins、挂点符号和其余 resident 字节不变，build id 改变，ABI 不变。三个交叉组合在 `rv_invoke` 前被拒绝。

M32R 对象直接测得 session 1,228 B、状态 6,144 B、UI 256 B，固定开销合计 7,628 B。最终 ELF 的 BSS 为 9,280 B，DAT 头也为此值。两包均满足：

```text
7,628 + align4(90,164 + 9,280) = 107,072 <= 107,612 B
90,164 <= 98,304 B
65,268 <= 65,536 B
```

效果容量和实用数量均为 10，行池容量为 8、28、32、32，实用为 0、10、9、10，效果区 6,636 B。三个用户条目从测试 DAT 的 UI 扩展读出，发布 DAT 为零。
