# M2 修图视图：浏览器手动检查清单

用途：在真机和真卡之前，在浏览器里逐项核对。自动化部分见 `browser_walkthrough_m2.mjs`（22 项无相机数据、24 项有相机数据）和 `studio/tests/test_web_m2_smoke.py`。

准备（只用假卡或临时目录，不要插真卡做这一步）：

```bash
cd studio
rm -rf /tmp/gxr-m2 && mkdir -p /tmp/gxr-m2/{vol,lib,exp}
uv run python -m gxr_studio.devtools.synthetic_card /tmp/gxr-m2/vol
GXR_STUDIO_VOLUMES=/tmp/gxr-m2/vol GXR_STUDIO_LIBRARY=/tmp/gxr-m2/lib GXR_STUDIO_EXPORT=/tmp/gxr-m2/exp \
GXR_STUDIO_TOKEN=check123 uv run gxr-studio --no-browser --port 8790
# 浏览器打开 http://127.0.0.1:8790/?token=check123
```

## A. 没有相机数据（默认状态）

- [ ] 大图点「配方」（或按 R）：左侧下方的说明写着「电脑预测」，并写出原因「请先插入装有配方程序（GXRCE.DAT）的存储卡…」。
- [ ] 右侧出现黄色边框的引导：「还没有导入相机数据」，里面有「从卡导入」和「选择 GXRCE.DAT 文件…」两个按钮，文字是大白话。
- [ ] 8 个底子都能点，点哪个哪个变成金色；「04 标准」旁边写着「原厂」。
- [ ] 点一根滑块拖动：没有图（不会报错），说明里的原因仍然在。
- [ ] 按住空格：说明变成「正在看照片本身…」；松开恢复。
- [ ] 点「全部归零」：按钮变成「再点一次：全部归零」，4 秒内不点就恢复；点第二次才清掉微调。
- [ ] 「存为我的配方（即将推出）」是灰的，点不了。
- [ ] 「调整」：每一行右边都有「仅电脑」小标签；曲线下面写着「0 / 16」之类的点数。
- [ ] 曲线：点空白处加点，拖动点；双击中间的点删掉；两端只能上下动；加到 16 个点后再点空白，提示「最多 16 个点」。
- [ ] 「导出」：没有「暂时不能导出」的字样；写着中性预览或电脑预测；有「精确（更慢）」勾选框。
- [ ] 只有 RAW 的照片（角标「只有 DNG」）：配方标签可以用（它有 RAW）。
- [ ] 只有 JPG 的照片（角标「只有 JPG」）：配方标签写「这张照片没有 RAW，只有相机 JPG，不能套配方。」，滑块不起作用。

## B. 有相机数据和标定包

准备：服务器的应用数据目录（`GXR_STUDIO_HOME`）里要有 `camera-data/` 和 `calib/`。本次走查用的是测试夹具从本机固件打包目录生成的临时目录，没有写进仓库；自动走查用 `GXR_CAMDATA=1 node browser_walkthrough_m2.mjs` 运行。

- [ ] 引导不再出现。
- [ ] 预览是图片，说明里的标签是「电脑预测」；未标定时后面有「（跨单元/跨 ISO，未标定）」和具体原因（例如「ISO 400 没有单独标定」）。
- [ ] 对比、高光、阴影、饱和度的标签是「相机 ±5」（旧版相机）；褪色、冷暖、品绿、分离色调、黑白滤镜的标签是「仅电脑」。
- [ ] 拖动滑块时预览很快跟着变（小图）；松手后换成清晰版。
- [ ] 03 高反差黑白：没有饱和度、冷暖、品绿、分离色调，也没有整体强度。
- [ ] 04 标准：没有整体强度。
- [ ] 整体强度：显示百分比，每格的步长写着「每格 10%」「20%」或「25%」，到顶的值后面有「!」。
- [ ] 换底子后，原来底子的微调保留；换回去时微调还在。
- [ ] 导出：有相机数据、有 RAW 的照片，写着「电脑预测的配方效果」；导出的文件名带「_电脑预测」。

## C. 目前还没法在这里检查的（需要接口或真机）

- [ ] 「从卡导入」「选择 GXRCE.DAT 文件」的按钮：接口 `/api/camdata/import-card`、`/api/camdata/import-file` 还没上线时，点按钮会显示接口的错误文字，不会有反应。上线后再检查：导入成功后预览自动出现。
- [ ] 标定包：界面没有导入入口，只会在预览说明里写「缺少电脑预测用的标定包」。
- [ ] 28mm 和 MOUNT 的照片：没有真实样本，标签的单元判断只按镜头名。
- [ ] 真实的相似度数字：界面不显示数字，只显示预览图和标签；数字以后再加。
