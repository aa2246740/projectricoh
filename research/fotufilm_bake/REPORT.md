# fotufilm 全部 47 种胶片烘焙成 LUT：一致性、相机相似度、推荐

2026-11-01。本轮在本机沙箱里运行了 fotufilm 的命令行，把它 47 个胶片档案的"颜色"烘焙成 33³ `.cube`，再用真实照片核对"LUT 和 fotufilm 本身"是否一致，最后算了两种相机相似度（都是**电脑预测**）。

本轮没有碰相机、存储卡或 `/Volumes/RICOHDCX`，没有生成上卡文件，没有 git 写操作，也没开子代理。

---

## 0. 结论

1. **47 种全部烘焙成功，全部达到"肉眼看不出"。**
   - 检验对象：6 张 GXR 街拍、114 万像素，用"引擎直接渲染"和"套 LUT"对比。
   - 色差（ΔE00）中位数 0.017–0.088，p99 0.065–0.73。目标是中位 <0.5、p99 <2，**47/47 通过**。
   - 最差的单个像素：Aerochrome 2.44、Infrared Color 1.99、Phoenix 200 1.69。它们都是假彩色或调色很陡的片种，33³ 格点之间插值会有一点误差。
   - 这里的"一致"有明确前提：
     - 颗粒、光晕、扩散都关掉；
     - 用固定定标，不用 Auto Levels；
     - 输入是 sRGB 照片；
     - 比的是逐像素的颜色。
2. **逐像素性先证明了。**
   - 每种胶片都把恒等格点和打乱顺序的格点放在同一次渲染里，输出逐像素完全相同（16 位码值差 0/65535）。
   - 这说明这次渲染没有任何空间效果，也没有按画面自动定标。LUT 里只有颜色。
3. **有三件事 LUT 做不到。**数字见第 2、5 节。
   - **邻接效应（局部反差）**：命令行关不掉。整幅原分辨率渲染和逐点渲染相比：
     - 多数胶片中位差 <0.3；
     - 富士系负片（PRO 160NS、PRO 400H、Reala 100、Superia 200/400、C200）和 Provia 100F 中位差 0.6–1.1，p99 5–8。
     - 差别和胶片档案里"邻接强度 × 半径"一一对应，是纹理、边缘层面的效果，不是颜色。大面积平涂区一致。
   - **Auto Levels（应用的默认模式）**：对屏幕介质的片种（所有反转片、Phoenix 200）逐张自动定标。同一张照片，它和固定烘焙差中位 0.1–3.8 ΔE00，Phoenix 200 差 7.8–21。
   - **颗粒和光晕**：按要求关闭，本来也放不进 LUT。
4. **相似度（电脑预测；用法是"接在 GXR 的 04 JPEG 后面"，和工作室里的用法一样）。**
   - **相机表近似**：
     - 黑白 87–89%（合成留出），实景 67–79%；
     - 彩色片多在 45–80%，余差 1.7–4.6 ΔE00；
     - 假彩色片（Aerochrome、红外、LomoChrome Purple/Turquoise）余差 10–18，相机表表达不了。
   - **机内 17³ 真 LUT**：
     - 全部 93–99.7%，余差 0.08–0.58；
     - 黑白最高 99.6%，反转片最低 93–96%。
   - 规划时这两列都按"相机实测会再低"来看：相机表历史上低 1–3 个百分点；机内 LUT 还没上机，可能再低 5–12 个百分点。
5. **推荐先进相机 7 种**：Tri-X 400、Velvia 50、Kodachrome 25、Portra 400、Vision3 500T、instax mini、LomoChrome Metropolis，理由见第 4 节。
   - 只建议在电脑工作室里用的：Aerochrome、Infrared Color、LomoChrome Purple/Turquoise、Phoenix 200、F-64D，以及要靠邻接效应才完整的富士负片和 Provia。

### 1.3 "只要颜色"的设置

每种胶片都用同一组参数：

```
--grain 0 --halation 0 --local-tone 0 --digital-reference reference-exposure --depth 16
```

- **颗粒、光晕**：设为 0。
- **扩散滤镜、镜头眩光、暗角**：默认就是关的，没有另外设。
- **局部影调**：`--local-tone 0`。实测开和关输出完全相同。
- **定标**：
  - `reference-exposure` 是固定定标：标准中灰，保留胶片自身反差。只对"屏幕"介质起作用，其他介质忽略它。
  - 选它而不选 `graded-print`，是因为试过的两种片（Velvia 50、Phoenix 200）在同一张照片上它离 Auto Levels 更近：差 3.9 / 8.2，后者是 6.2 / 11.1。
- **介质**：用每种胶片自己的默认（`PrintPaper.default(for:)`），和命令行、应用不指定时一样：
  - 普通负片：Ektacolor Edge 相纸；
  - 电影负片：各自的拷贝片（Vision 2383 或 Eterna-CP）；
  - 反转片、Phoenix 200、instax：屏幕。
- **其余空间效果**：乳剂扩散、邻接、耦合剂扩散、放大机模糊，这些命令行关不掉。
  - 做法是把输入画面做成只有 **4 像素高**的长条（格点是 17969×4）。引擎按"胶片毫米 × 每毫米像素数"换算半径，这时所有空间半径都低于它自己的 0.15 像素截断，变成恒等。
  - 胶片档案里最大的空间半径是 Astia 的邻接 0.37 mm，4 像素高时仍低于截断。
  - 打乱顺序检验（第 0 节第 2 点）每种都通过，证明确实逐像素。
- **输入**：sRGB 码值的 16 位 PNG。引擎按 sRGB 解码成线性 Rec.2020。
- **输出**：命令行写的是 **Display P3**（sRGB 传递曲线）16 位 PNG，16 位不加抖动。
  - 每种胶片出两个文件：
    - `fotufilm_<id>_srgb.cube`：sRGB 进、sRGB 出。P3 输出在线性光里转成 sRGB，超出色域的裁掉。**给我们的 LUT 工具和相机用这个。**
    - `fotufilm_<id>_p3out.cube`：sRGB 进、Display P3 出，就是 fotufilm 写进文件的值，要按 P3 显示。
  - 33³ 格点里超出 sRGB 的节点占 0–65%，在饱和色那一角，表里有一列。
  - 实际照片中极饱和的颜色，sRGB 版会比 fotufilm 的 P3 文件略淡。这是 sRGB 色域本身的限制，不是 LUT 误差。

### 1.4 一致性验证

- **照片**：R8051530、554、570、586、594、610，都只读。
  - 选的标准是亮暗、饱和度各不相同；黑白相机直出的那些没选。
  - 先缩到 1/8，共 114 万像素，再存成 8 位 sRGB 码值。两边吃的是同一份像素，排除了解码器差异。
- **逐点对比**（主表）：
  - 同样的像素做成 4 像素高的长条，用 fotufilm 渲染；
  - 另一边用烘焙出的 33³ LUT 做四面体插值；
  - 在 CIELAB（D65）里算 ΔE00。
  - 附带算了：P3 版、三线性插值、LUT 输出再取整到 8 位后的数字。
- **整幅对比**（副表）：
  - R8051530、R8051586 按 1/4 尺寸（1072×712）当正常一幅渲染。这时它的邻接、扩散这些空间效果是开着的。
  - 和逐点渲染、和 LUT 分别比；
  - 再做 8×8 低通后比一次，用来区分"边缘、纹理"和"颜色"。
- **Auto Levels**：屏幕介质的 13 种，用默认 Auto Levels 渲染整幅，低通后和 LUT 比。

### 1.5 相似度

- **工具**：`camera.py`、`ceiling.py`、`convert.py`、`cube.py`、`fit.py`、`spaces.py`、`guard.py` 复制自 `research/film_engines_eval`，那边又来自 `film_look_routes` 和 `lut_convert`。
  - 改动只有两处：`guard.py` 的写入围栏改到本目录；`ceiling.py` 第一行改成来源说明。
  - 驱动脚本是新写的 `similarity.py`，做法和 `engines_ceiling.py` 相同：50mm 的 04 模型、同样 4 张 DNG 场景、同一套留出合成色（种子 20261023）和第 4 张整图留出。
- **百分比** = `1 − 中位色差(结果→目标) / 中位色差(04→目标)`。
- **机内 LUT**：Q8.8 节点、三线性、λ=0.1。没有模拟 4:2:2 色度共用和 JPEG 再压缩，`body_lut` 估过这部分约损失 1–1.5 个百分点。
- **两种用法**：
  - **接 04 JPEG**（主）：fotufilm 吃 GXR 的 JPEG，等于在电脑工作室里给 GXR 照片套这个 LUT；
  - **场景光**（对照）：把 DNG 的场景线性光按 sRGB 编码后喂进去，不经过 04 的影调曲线。

- **前提**：相机表近似现在就能做，不需要机身更新。机内真 LUT 通了以后，这 7 种都能到 94–99.6%。
- **余差**：表里是"接 04 JPEG"用法的相机表余差。

| 类别 | 胶片 | 相机表（合成 / 实景） | 余差 | 机内 17³ | 理由 |
|---|---|---:|---:|---:|---|
| 黑白 | **Tri-X 400** | 88.1% / 70.4% | 3.23（场景光用法 1.52） | 99.6% | 黑白各片互相只差 0.5–1.5，选一支最有代表性的即可。富士 Acros 已有 `film_look_routes` 的路线，不重复 |
| 反转片 | **Velvia 50** | 66.3% / 68.0% | 2.25 | 94.4% | 高饱和风景片，离最近的 Ektachrome 差 1.5 |
| 反转片 | **Kodachrome 25** | 66.8% / 65.2% | **1.80** | 94.9% | 反转片里相机表余差最小之一。和 Velvia 风格分得开，最近的 Kodachrome 200 差 1.6 |
| 彩色负片 | **Portra 400** | 61.2% / 53.3% | 2.87 | 96.8% | 柯达负片的代表，Gold、UltraMax、Kodacolor 都在 2.1 以内。只能"像个大概" |
| 电影卷 | **Vision3 500T** | 76.7% / 63.0% | **1.92** | 97.1% | 和 250D 只差 0.7，二选一。彩色负片里相机表最像的一档 |
| 拍立得 | **instax mini** | 72.7% / 78.1% | 2.39 | 97.1% | 实景 78%，彩色片里最高。wide 和它几乎一样 |
| 特殊 | **LomoChrome Metropolis** | 80.4% / 69.5% | 3.03（场景光用法 1.77） | 98.5% | 低饱和、偏青的强烈风格，离任何其他片都远（最近的 Turquoise 也差 4.8），相机表还能表达 |

- **可选替换**：
  - Provia 100F：余差 1.88，标准反转；
  - Lomo Color 100：彩色负片里相机表最好，74% / 71%，余差 2.30，但名气小；
  - Eterna 500：电影感低反差，余差 3.02。
- **黑白和 Metropolis 的"场景光"用法**余差明显更小（1.1–1.8 对 3.0–3.6）：
  - 如果上机时允许按 DNG 场景光来拟合，这两类优先用场景光版本；
  - 代价是和工作室里"给 JPEG 套 LUT"的结果不完全相同。
- **反转片要提醒用户**：fotufilm 应用默认用 Auto Levels，每张照片单独定标；我们的固定版和它在同一张照片上差 0.1–3.8。所以"和 fotufilm 一样"指的是它的 Reference Exposure 模式。

### 4.2 只适合电脑工作室的

| 胶片 | 原因 |
|---|---|
| Aerochrome 1443、Infrared Color | 假彩色，相机表余差 18 和 11，表达不了。机内 17³ 有 98.5–98.6%，等真 LUT |
| LomoChrome Purple、Turquoise | 余差 12 和 11，同上 |
| Phoenix 200 | 余差 5.9；应用默认 Auto Levels 和固定版差 7.8–21，换了照片就不是同一个样子 |
| F-64D | 余差 4.6，而且邻接效应明显 |
| Ektar 100、Reala 100、Superia 200、PRO 160NS/400H | 余差 3.6–4.2。富士这几支的完整观感还依赖邻接效应（中位 0.6–1.1、p99 5–8），只有电脑工作室能补上空间部分 |
| Provia 100F | 颜色可以上机（余差 1.88），但整幅观感的邻接效应 p99 8.4，完整版放工作室 |

其余胶片（Agfachrome、Astia、Ektachrome、Kodachrome 64/200、Gold、UltraMax、C200、CineStill、Eterna、Reala 500D、Verita、Aerocolor、HP5、FP4、Delta、T-MAX、Double-X、Acros）：工作室里全部可用。上机等机内真 LUT，或者以后从同组里替换。

### 4.3 工作室里怎么用

- 给 GXR 的 sRGB JPEG 直接套 `_srgb.cube`，就是"fotufilm 固定模式、关掉颗粒和光晕"的颜色，色差中位 <0.1。
- 想要 fotufilm 的 P3 色域，用 `_p3out.cube`，并把输出标成 Display P3。
- 颗粒、光晕、邻接这些空间效果另外做，见 `film_engines_eval` 第 4 节。

## 5. Auto Levels 与固定烘焙的差别

只对屏幕介质的 13 种（反转片、Phoenix 200）。8×8 低通后比较，所以剩下的只是逐张定标带来的差别。
