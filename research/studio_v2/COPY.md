# GXR Studio 界面文案规范（必须遵守）

编排者写于 2026-10-30。用户的反馈是："文案太 slop，这些功能都有约定俗成的叫法，参考 Lightroom、Capture One、Snapseed，别乱发明。"本文件约束前端和后端所有给用户看的文字。**本文件没有覆盖到的文字，不要自己造词**：先用术语表里最接近的词，再记进 `COPY_GAPS.md`，等编排者定。

## 1. 原则

1. **用现成的叫法。** 优先顺序：苹果"照片"App（简体中文）→ Lightroom（简体中文）→ Capture One / Snapseed。下面的术语表是强制的。
2. **控件只写名词标签，2 到 4 个字。** 控件下面不加说明句，不写"往右拉：楼顶变宽"或"线条往外鼓时往右拉"这类话。数值直接显示在标签右边。
3. **不安慰、不教学。** 不写"原图没有被改动""随时可以还原""放心""看上面的提示"。功能怎么用，靠控件本身和快捷键表。
4. **按钮用动词**，比如：导入、导出、完成、取消、重置、复原、撤销、重做、自动、应用、存储。
5. **状态和提示最多一句。** 写法：
   - 进度："正在导出 3/12"
   - 结果："已导出 12 张"
   - 出错：发生了什么 + 怎么办，两句以内，例如"无法读取存储卡。请重新插入后重试。"
6. **空状态**：一行字 + 一个按钮，例如"还没有照片" + [导入照片]。
7. **提示气泡**只写快捷键或一句定义，例如"拉直（↑/↓ 每次 0.5°）"。
8. **中英混排**：
   - 保留 RAW、JPEG、DNG、LUT、XPan、ISO、EXIF 以及平台名（Instagram、小红书、微博、抖音）。
   - 英文和数字两侧各留一个空格，数字和单位之间不留空格："ISO 200""1/250s""f/2.5""+0.7""+1.2°"。
   - 尺寸写作"4288 × 2848"，乘号两侧留空格。
9. **标点**：只有一句话时，句末不加句号。两句以上才加句号。

## 3. 各面板的固定文案

### 3.1 裁剪
标题就是"裁剪"，不另加副标题，也不放说明段落。

```
比例        [原始 ▾]        [横向|纵向]
参考线      [三等分 ▾]
拉直        +1.2°
垂直        0
水平        0
畸变        0
[自动] [向左旋转] [水平翻转]                [重置]
```

- 比例下拉分两组：
  - 常用：原始、自由、1:1、4:5、3:2、16:9、XPan 65:24
  - 社交媒体：Instagram 4:5、Instagram 1.91:1、小红书 3:4、9:16
- 尺寸提示放在画面角落，只写数字：`4288 × 2848`。
- 自动纠正没有把握时，提示"未检测到明显的水平线"。

### 3.2 调整
曝光、对比度、高光、阴影、黑点、饱和度、自然饱和度、色温、色调、暗角，下面单独一组"曲线"，配 [重置]。不加分组说明。

### 3.3 配方
```
内置配方     01 GR 正片 … 08 徕卡 Vivid   (配方名沿用相机里的名字)
我的配方     …
强度         100%
对比度 / 高光 / 阴影 / 饱和度 / 色温 / 色调 / 分离色调 / 褪色 / 黑白滤镜
[存储为我的配方] [写入存储卡]                [重置]
```

- 角标只用"电脑预测"或"近似"。
- 只有 JPG、做不了近似时，面板里只写一行："配方需要 RAW 文件"，下面一行小字："拍摄时将画质设为 RAW+JPEG"。按钮置灰。

### 3.4 边框
样式卡片，文字写在卡片下方：

| ID | 名称 |
| --- | --- |
| none | 无 |
| gallery | 白边 |
| leica | 徕卡水印 |
| hasselblad | 哈苏水印 |
| film | 胶片 |
| instant | 拍立得 |
| canvas | 画布 |

选项：颜色（白 / 黑 / 米白）、宽度（细 / 中 / 粗）、显示（标志 / 参数 / 日期）、文字、画布比例（1:1 / 4:5 / 3:2 / 9:16）。底部按钮：[设为默认]。

### 3.5 时间戳
```
时间戳        [开关]
内容          日期 / 文字 / 日期和文字
格式          '26 10 30 ▾      (下拉里直接列出示例，不写格式代码)
显示时间      [开关]
指定日期      [日期选择器]       (留空 = 拍摄日期)
文字          [输入框，最多 24 字]
字体          数码管 / 打字机 / 无衬线
颜色          橙 / 红 / 黄 / 白
大小          小 / 中 / 大
位置          左上 / 右上 / 左下 / 右下
发光          [开关]
```

照片没有拍摄时间时，在"指定日期"下面显示一行小字："使用文件修改日期"。

### 3.6 导出
格式 JPEG、品质（数值）、尺寸（原始尺寸 / 长边 2048 像素 / 长边 4096 像素）、导出到、文件名。底部按钮：[导出]、[取消]。

- 进度："正在导出 3/12"
- 完成："已导出 12 张" + [在访达中显示]

### 3.7 导入与图库
- 空状态："还没有照片" + [导入照片]
- 进度："正在导入 12/40"
- 完成："已导入 40 张"
- 取消："已取消，已导入的 12 张已保留"
- 读卡出错："无法读取存储卡。请重新插入后重试。"
- macOS 不允许访问外接卡："需要访问存储卡的权限。请在"系统设置 › 隐私与安全性 › 文件与文件夹"中允许。"

### 3.8 通用
- 连接失败："无法连接到 GXR Studio。请确认启动窗口仍在运行，然后刷新页面。"
- 保存：成功不提示；失败写"无法保存修改。请重试。"
- 快捷键：集中放在 [?] 打开的"快捷键"表里，面板里不写。

## 3.13 补充裁定 5：后端文字的结构（回应验收 V2-17，2026-10-31）

1. **两层分开。**
   - 错误响应的 `message` 只写给用户看，用"发生了什么。怎么办。"两短句，或者"无法 + 动作 + 对象。原因。"。
   - 异常原文、文件路径、内部键名（max_edge、knobs v2、thumb/preview/full 之类）、版本号细节，一律放进 `detail`。前端放在"详细信息"折叠区里，默认收起。
2. **界面上点不到的错误**（只有直接调接口传错参数才会出现）：`message` 统一写"请求无效。请刷新页面后重试。"，具体原因放 `detail`。
3. **状态说明和 note 字段**：`/capabilities` 的 `reason`、LUT 的 `note`、渲染的 `note` 都不写教学句，也不交代来源。要么写一个短状态，例如"配方需要 RAW 文件""请先导入相机配方文件"，要么直接删掉。
4. **术语**：调色文件 → LUT；存到 → 导出到；导出文件夹 → 导出到；照片本身 → 原图；输入空间是猜的 → 推测（小标签）。
5. **常用句式**：
   - 编辑冲突："这张照片已在别处修改。请刷新后重试。"
   - 读不出 RAW："无法读取 RAW 文件。文件可能已损坏。"
   - 文件过大："无法读取 LUT。文件过大。"、"无法导入相机配方文件。文件过大。"
   - 编辑记录来自更新的版本："这张照片的编辑来自更新的版本。请更新 GXR Studio。"
   - 电脑预测算不出来："无法生成电脑预测。请重试。"
