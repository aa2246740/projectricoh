# GXR 电脑工作室 v2 · 界面设计

状态：第一阶段设计稿（前端设计师，2026-10-30）。配套文件：`prototype.html`（可点击原型）、`IMPLEMENTATION_PLAN.md`（实现计划）、`CONTRACT_REQUESTS.md`（合同需要裁定的地方）。
依据：`research/studio_v2/PRD.md`（以它为准）；现有界面 `studio/web/`；已有 UX 稿 `research/studio_design/UX.md`。

所有预览都是**电脑预测**或**近似**，不是相机实拍。界面上要写清楚。

---

## 0. 设计目标（一句话）

用户拍完照，在这里**一步步做完裁切、纠正、换风格、加边框和日期戳**，页面上看到的就是导出的样子。功能少，但每一项都好用、好看、说得清楚。

视觉语言沿用现有深色界面（`app.css` 的配色和间距），新增一套浅色配色，两套都要清楚。

## 1. 查看器（大图）的整体布局

### 1.1 页面框架

```
┌──────────────────────────────────────────────────────────────────────────┐
│ GXR 电脑工作室        照片  配方  相机                    导出   设置   ? │  顶栏 52px（与现在一样）
├──────────────────────────────────────────────────────────────────────────┤
│ ‹ 返回图库   R8051224   10-23 14:05   [RAW+JPG]  [只有 JPG]     3 / 24  │  照片条 40px
├────────────────────────────────────────────────────┬─────────────────────┤
│                                                    │ 配方 调节 裁切 边框 │
│                                                    │ 时间戳 导出         │  侧栏 380px
│                 画面（成片预览 或 裁切中）            │ ─────────────────── │
│                                                    │                     │
│                                                    │   当前标签的内容     │
│                                                    │                     │
├────────────────────────────────────────────────────┤                     │
│ [电脑预测]  成片预览 · 已保存                         │                     │  状态行 32px
├────────────────────────────────────────────────────┴─────────────────────┤
│ ↶ 撤销   全部还原                          ‹ 上一张      下一张 ›        │  底栏 44px
└──────────────────────────────────────────────────────────────────────────┘
```

- 舞台（画面区）占左边剩下的全部宽度，画面等比放大缩小，居中。
- 侧栏固定 380px。窗口窄于 1100px 时侧栏降到 340px，标签字号不变。
- 底栏只放两类按钮：**改动相关**（撤销、全部还原）和**换照片**（上一张、下一张）。导出不放在底栏。

### 1.2 标签怎么排

顺序：**配方 · 调节 · 裁切 · 边框 · 时间戳 · 导出**。六个标签等宽，每个 63px，正好放下两到三个字。

| 标签 | 快捷键 | 进去之后的标题 | 画面状态 |
|---|---|---|---|
| 配方 | R | 配方 | 成片预览 |
| 调节 | A | 调节 | 成片预览 |
| 裁切 | C | 裁切与纠正 | **裁切中** |
| 边框 | F | 边框 | 成片预览 |
| 时间戳 | T | 时间戳 | 成片预览 |
| 导出 | E | 导出 | 成片预览 |

- 标签栏上只写两个字「裁切」，进去的标题写「裁切与纠正」。这是因为六个标签必须挤在 380px 里。
- 标签的提示文字（鼠标悬停）写「裁切与纠正（C）」这样的全称。
- 默认打开的标签是上一次看的那个（和现在一样）。

### 1.3 「成片预览」和「裁切中」怎么切换

这是整个查看器最重要的一条规则，目的是消除现在"两种预览来回跳"的问题。

**只有一条规则：选中「裁切」标签，画面进入「裁切中」；选中其它任何标签，画面都是「成片预览」。** 不靠别的开关。

| 状态 | 画面里有什么 | 画面里没有什么 | 什么时候出现 |
|---|---|---|---|
| **成片预览**（默认） | 配方、调节、纠正、裁切、时间戳、边框，全部都在 | — | 除「裁切」外的所有标签 |
| **裁切中** | 整张未裁切的画面，已经做了颜色和纠正（拉直、透视、畸变、旋转翻转）；亮框标出保留的部分，框外变暗 | 时间戳、边框（它们不参与裁切） | 选中「裁切」标签 |
| **原图**（按住空格键） | 没有任何编辑的照片本身 | — | 按住空格，松开恢复 |

切换的细节：
- 进入或离开「裁切中」时，画面淡入淡出，约 150 毫秒。
- 「裁切」标签底部有「完成」按钮，点它回到**刚才那个标签**（默认回到「配方」），画面变成成片预览。
- 切换标签不会重新读照片，也不会丢掉没保存的滑块位置。

状态行（画面下面那一行）：
- 左边是**标签**（见第 4.3 节的表），右边是**保存状态**：「正在预览…」「已保存」「预览没成功」。
- 在「裁切中」时，左边写：「裁切中：这是整张画面，亮框里是会保留的部分。」

### 1.4 照片条与底栏

- 照片条（画面上面一行）：返回图库、文件名、拍摄时间和日期、格式标签、「日期是估计的」（只有没拍摄时间时才出现）、第几张 / 总共几张。
- 底栏左边：「撤销」（⌘Z，最多 100 步，换照片后清空）和「全部还原」。「全部还原」清掉这张照片的**所有**编辑（裁切、纠正、调节、配方、边框、时间戳），原图不动。点一下就执行，并提示「已还原，可以用撤销找回来」，不弹确认框。
- 底栏右边：「上一张」「下一张」。

## 2. 裁切与纠正面板（对齐苹果相册的「裁剪」页）

侧栏「裁切」标签里，从上到下：

```
裁切与纠正
原图没有被改动。裁切和纠正随时可以还原。

比例   [ 原比例 ▾ ]   [ 横 | 竖 ]          （横竖切换只在能横竖的比例上可用）
       [⟲ 逆时针转 90°]  [⇆ 左右翻转]

拉直                                   +1.2°
  ┃┃┃┃┃┃┃┃┃▮┃┃┃┃┃┃┃┃┃┃┃              （刻度盘：拖动转动，每格 1°）

透视（把歪的楼摆正）
  垂直   ◀━━━━━━━●━━━━━━━▶   0
  水平   ◀━━━━━━━●━━━━━━━▶   0

镜头畸变   ◀━━━━━━━●━━━━━━━▶   0
           A12 镜头一般用不着；转接老镜头时才用。

[ 自动 ]   [ 还原裁切和纠正 ]

框的大小   ━━━━━━━━━━━━●━━━   100%
构图辅助线  [三分线 ▾]      ☑ 拖动时看清，松手后变淡

当前：3:2（横），裁出 4288 × 2848 像素
```

### 2.1 比例

- 一个按钮「比例：原比例 ▾」，点开是菜单，分两组：
  - **常用**：原比例、自由、1:1、3:2、4:3、16:9、XPan 65:24
  - **社交媒体与屏幕**：小红书 3:4、Instagram 4:5、Instagram 1:1、Instagram 横图 1.91:1、公众号封面 2.35:1、微博 16:9、抖音 / 视频号 9:16、电脑壁纸 16:10
- 横竖切换放在比例按钮右边，只在能横竖的比例上可以用。原比例、自由、1:1 这三个不分横竖，按钮显示灰色，悬停提示「这个比例横竖一样」。
- 选了比例，裁切框自动变成当前画面里**最大的、居中的**那个框。
- XPan 65:24 下面保留现在的小字说明：「全景条，适合横向景物。」

### 2.2 旋转 90° 和翻转

- 「逆时针转 90°」：每点一次转 90°。框跟着画面一起转（按坐标换算，不重算、不丢掉用户已经框好的范围）。
- 「左右翻转」：镜像。框跟着翻。
- 两个按钮都写字，不只放图标（小白看得懂）。

### 2.3 拉直（刻度盘）

- 范围 −45° 到 +45°，步长 0.1°。
- 做成一条横向刻度盘：中间一根固定的指针，刻度跟着拖动移动，每格 1°，每 5° 一根长线，每 10° 写数字。拖动一下转一下。
- 双击刻度盘归零。
- 数字显示在右上角：「+1.2°」「0.0°」「−3.5°」。
- 键盘：获得焦点后 ←/→ 每次 0.1°。↑/↓ 每次 0.5°（和现在一样，没有焦点时也生效，见第 8 节）。
- 刻度盘拖动时，画面**立即**跟着转（用浏览器直接旋转，不等电脑）。松手后请电脑算出准确画面。

### 2.4 透视：垂直、水平

- 垂直（−100 到 +100）：**拍楼仰拍、楼顶变窄时用**。约定：往右拉（正数）让楼顶变宽、摆正。0 不动。滑块下面一行小字：「往右拉：楼顶变宽」。
- 水平（−100 到 +100）：左右歪斜的透视时用。约定：正数往右拉，画面右边变宽。0 不动。滑块下面一行小字：「往右拉：右边变宽」。
- 两个滑块中间有一个小的中心标记，双击归零。
- 数值范围和方向的最终定义以后端为准，见 `CONTRACT_REQUESTS.md` 第 9 条。

### 2.5 镜头畸变

- −100 到 +100，0 不动。
- 说明：「线条往外鼓（像桶）时往右拉；往里凹（像枕头）时往左拉。A12 镜头一般不用调，转接老镜头时才用。」
- 放在透视下面，和透视是同一组，但单独一行。

### 2.6 自动

- 点「自动」，电脑找地平线和竖直线，给出拉直和垂直的建议值。
- 找到了：把建议值填进去，并写一行「已拉直 +1.2°，垂直 −3。可以再调，或用撤销。」
- 没把握：**不改任何值**，写「没找到明显的水平线，没有改动。可以手动拉直。」
- 自动的每一步都进撤销栈。

### 2.7 还原

- 「还原裁切和纠正」：比例、拉直、透视、畸变、旋转、翻转、框的位置和大小全部回到原图。
- 只清裁切和纠正，**不动**配方、调节、边框、时间戳。（底栏的「全部还原」才会全清。）
- 点一下就执行，写「已还原裁切和纠正」，可以撤销。

### 2.8 框的规则

1. **处理顺序**：畸变 → 透视（垂直、水平）→ 拉直 → 旋转和翻转 → 裁切。画面和框都按这个顺序理解。
2. **框不出现空白角**：只要拉直、透视或畸变让画面边缘空了，框会自动缩小、收进有效画面里（以框的中心为准，等比缩小）。状态行写一行「框已收进有效画面」，2 秒后淡掉。
3. **用户手动拖出界的框**：松手时自动缩回有效画面里，同样提示一行。
4. **拖动框**：在框里拖动挪位置；拖四个角缩放（比例锁定时保持比例）；「框的大小」滑块从中心缩放。
5. **构图辅助线**：G 键循环（关、三分线、黄金比例、黄金螺旋、对角线、中心十字、网格 4×4）；O 键换螺旋方向。拖动框或滑块时辅助线完整显示；松手后按「变淡」设置变淡。
6. 这些设置（辅助线类型、变淡）只存在这台电脑的浏览器里，不写进照片。

### 2.9 默认值

| 控件 | 默认值 |
|---|---|
| 比例 | 原比例 |
| 横竖 | 跟着照片 |
| 拉直 | 0.0° |
| 垂直 / 水平 / 镜头畸变 | 0 |
| 旋转 | 不转 |
| 翻转 | 不翻 |
| 框的大小 | 100%（最大） |
| 构图辅助线 | 三分线（拖动时看清：开） |

侧栏「调节」标签。顶上一行：「⚠ 这里的调节只在电脑上生效，不会写进相机配方。」（这句话保留，是诚实说明。）

### 3.1 四个新项（PRD 第 3 节）

| 项 | 范围 | 放在哪 | 一句话说明 | 方向约定（待后端确认） |
|---|---|---|---|---|
| 黑点 | −100 到 +100 | 光线，阴影下面 | 调黑色的深浅 | 正数压黑，负数发灰 |
| 饱和度 | −100 到 +100 | 颜色，色调下面 | 整体颜色浓淡 | 正数更艳 |
| 自然饱和度 | −100 到 +100 | 颜色，饱和度下面 | 先把淡的颜色提起来，皮肤不容易过艳 | 正数更艳 |
| 暗角 | −100 到 +100 | 效果（单独一组） | 负值压暗四角，正值提亮四角 | 负数压暗（PRD 已定） |

- 「自然饱和度」的说明写在滑块下面，不写英文。
- 不加锐化、降噪、清晰度（PRD 第 3 节）。

### 3.2 其它调节项

- 曝光：−5 到 +5 挡，步长 0.1。「挡」是摄影的常用说法，不写 EV。
- 对比、高光、阴影：−100 到 +100。
- 色温、色调：沿用现在的 −100 到 +100。
- 曲线：沿用现在的主曲线编辑（最多 16 个点），两端固定。

### 3.3 交互

- 滑块上双击归零；拖动时画面用电脑预览（防抖，见第 4.5 节）；松手后保存。
- 「全部归零」：第一次点变成「再点一次：全部归零」，4 秒内第二次点才生效（沿用现在的做法）。只清调节和曲线，不动配方。
- 数字右对齐、等宽。只有色温、色调、黑点、暗角、自然饱和度这几项在滑块下面写一行两端的说明（见第 3 节的示意）。

### 3.4 默认值

曝光 0.0 挡；对比、高光、阴影、黑点、色温、色调、饱和度、自然饱和度、暗角都是 0；曲线为无（直线）。

- 「底子」「微调」的名字全部用中文（沿用现在的 `KNOB_NAMES`），**不显示**相机菜单里的英文缩写（Cont、High、Shad 等）。
- 每个底子各自记住自己的微调（和相机一样）。
- 黑白 03：隐藏「饱和度、冷暖、品绿、分离色调」，只显示「黑白滤镜」。
- 「相机 ±5」「仅电脑」两个小标签沿用现在的规则（PRD 没有改这部分）。

### 4.2 三种状态（按 `/api/photos/{id}/capabilities` 的 `recipe` 字段）

| `recipe` | 含义 | 配方面板 | 配方按钮 | 画面标签 |
|---|---|---|---|---|
| **full** | 有 RAW，配方是真的 | 不显示提示卡 | 可用 | 电脑预测 |
| **approx** | 没有 RAW，电脑用 JPG 近似算出来的 | 琥珀色提示卡（见下） | 可用 | 近似（这张没有 RAW） |
| **none** | 没有 RAW，也没有近似方法 | 灰色提示卡（见下），8 个底子置灰 | **置灰，点了会给出原因** | 不显示配方效果，画面是照片本身 |

提示卡文字（固定写法，`reason` 字段只作为后面的补充，见 `CONTRACT_REQUESTS.md` 第 6 条）：

- **approx**（琥珀色）：
  > **近似**：这张照片没有 RAW（原始文件）。下面的配方是用 JPG 近似算出来的，和 RAW 拍出来的会有差别。

- **none**（灰色）：
  > **这张照片用不了配方**
  > 这张只有 JPG，没有 RAW（原始文件），配方需要 RAW 才能算。
  > 以后拍的时候把画质设成 **RAW+JPEG**，就能套配方了。
  > 裁切、纠正、调节、边框、时间戳照常可以用。

### 4.3 「置灰」怎么做，才不会「点了没反应」

- 置灰的按钮用 `aria-disabled="true"`（不用 `disabled`），所以仍然能悬停、能获得焦点。
- 点它时，提示卡轻轻闪一下（一次，约 400 毫秒），同时卡片里的第一句变成加粗，并在提示卡下面写一行：「这张只有 JPG，所以配方按钮不能用。」
- 悬停提示：「这张只有 JPG，没有 RAW，不能套配方。」

### 4.4 画面上的标签（状态行左边）

| 情况 | 标签 | 颜色 |
|---|---|---|
| 有 RAW（`full`），不论有没有选配方 | 电脑预测（没选配方时是原厂 04 标准的预测） | 绿 |
| 只有 JPG，选了配方（`approx`） | 近似（这张没有 RAW） | 琥珀 |
| 只有 JPG，没选配方，或配方不能用（`none`） | 不显示标签（画面就是照片本身） | — |
| 只有 RAW，没有导入相机数据 | 中性转换（不是相机的颜色） | 灰 |
| 只有 RAW，RAW 读不出来，用了内嵌小图 | 内嵌小图（不是配方预测） | 灰 |

- 只有 JPG 的照片，调节、纠正、裁切、边框、时间戳都不会让画面变成「电脑预测」：它们只是对照片本身做普通的图像运算，所以不贴标签。
- 标签的来源：`full` 和 `approx` 由 `/capabilities` 决定；RAW 相关的两种中性画面沿用现在 `look_notes.js` 的判断。

这些文字沿用 `look_notes.js` 里已经写好的句子，不另起新文案。

### 4.5 预览刷新

- 滑块拖动时：防抖 120 毫秒，请求小图，旧图保持显示直到新图到了（不闪白）。
- 松手后：请求清晰版，**1.5 秒内**要看到新图。
- 状态行右边写「正在预览…」；预览失败时在画面下面写红字「预览没成功：（原因）」，并给「重试」按钮。上一张好的图保留，但变暗一点。

## 12. 需要编排者裁定的设计选择

这些是设计师（我）做了选择、但会影响产品的地方。前端先按下面的写，如果裁定不同，只改默认值，不改结构。

1. **边框默认：不加边框。** 理由：新照片第一眼看到的就是照片本身；边框和时间戳需要用户主动选。备选：默认「画廊白边 · 中 · 白」（更「一键好看」，但每张导出都会多一圈边）。
2. **时间戳默认：关。** 理由同上，并且不把日期戳强加给每一张照片。备选：默认开（数码管 · 橙 · 中 · 右下 · 发光，这一组本身是好看的）。
3. **标签名「裁切」**，进去的标题写「裁切与纠正」。PRD 写的是「裁切与纠正」；六个标签只能写两个字。
4. **「JPG」「RAW」两个词保留在界面上。** 用户、PRD 和相机菜单都在用，改成中文反而不好找。其余英文按第 11 节改写。
5. **「全部还原」点一下就执行**（不二次确认），靠撤销兜底。理由：沿用现在「还原原图」的做法。如果要改成二次确认，只需要把「再点一次」的做法搬过来。
6. **侧栏 380px，六个标签**。如果裁定要保留现在的四个标签（不加边框、时间戳的入口），就需要把边框和时间戳放进「导出」标签下面的「修饰」分组，这会让两项都难找，不推荐。

## 13. 视觉与配色

### 13.1 原则

- 安静克制：界面本身不抢照片的风头。画面周围只有一圈很淡的底色。
- 质感：面板之间用一根细线分开，不用阴影堆叠；按钮圆角 8px；卡片圆角 10px。
- 金色只用来表示「当前选中」和「主要动作」，不用于装饰。
- 参考：哈苏、徕卡的出片界面（大面积留白、数字用等宽字体）、苹果相册的编辑页（滑块、刻度盘、标签栏）。

- 所有文字组合都在 4.5:1 以上。

### 13.3 字体

- 界面：系统字体（苹方、冬青黑体、微软雅黑回退），与现在一样。
- 数字：等宽（`font-variant-numeric: tabular-nums`），滑块数值不跳。
- 时间戳字体：数码管（DSEG7 Classic，后端提供正式字体文件）。原型用等宽字体加发光模拟。
- 手写风（拍立得文字）：楷体回退（`Kaiti SC`、`STKaiti`、`楷体`）。正式版字体由后端提供。

### 13.4 动效

- 标签切换、「裁切中」淡入淡出：150 毫秒。
- 框收进有效画面：100 毫秒的缓动。
- 尊重系统的「减少动态效果」设置：开了就全部不动。

### 13.5 浅色与深色

- 默认跟随系统（`prefers-color-scheme`）。不做单独的切换按钮（本阶段不加设置项）。
- 原型里有一个切换按钮，只为了方便审看两套配色。

## 14. 无障碍与操作细节

- 所有可点的东西都能用键盘到达，焦点有 2px 金色外框。
- 滑块、刻度盘都有可读的数值（`aria-valuetext`，例如「+1.2 度」）。
- 按钮最小高度 28px；滑块的拇指 16px。
- 颜色不是唯一的信息：「已选」用金色底 + 文字「已选」或勾号；「置灰」用虚线边框 + 文字原因。
- 文字不小于 12px。
