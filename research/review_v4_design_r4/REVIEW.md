## 空间账

复跑只读数据核算，与交付结果逐项相同；又独立按段长与公式核账。冻结 g152 文件为 90,156 B，代码 63,896 B，BSS 9,252 B。十个效果的描述和引用行在紧凑前后逐项一致；此证据只证明数据关系，未执行修改后解析器。

```text

移出数据：3,408 + 7,904 = 11,312 B。
资源包：128 + 11,312 = 11,440 B；16,384 B 槽还余 4,944 B。

DAT 文件：90,156 − 4,592 − 11,312 + 2,048 + 1,132 + 512 − 3,072 = 74,872 B。
DAT BSS：9,252 + 192 + 28 = 9,472 B。
父请求：7,708 + 12,288 + align4(74,872 + 9,472) = 104,340 B。
DAT 代码：63,896 + 2,048 + 1,132 + 512 − 3,072 = 64,516 B。
```
