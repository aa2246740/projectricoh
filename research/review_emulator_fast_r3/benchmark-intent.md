正式计时前固定口径：严格注册流、四项修正全关、unit-off、fast 模式和 batching。比较旧 fix_r1 Python 设备参考与 strict_r2 原生设备，两个后端均用新进程。

MAIN 测 50,000,000 条指令的 cpu.run，构造与独立全状态哈希在计时外。输入驱动测原 input_run 与 native_input_run 的完整 run 调用，包含构造、执行和原有 CPU 检查点写入，扣除额外审计导出的时间。每项五对，顺序 reference/native，所有样本保留。

要核实的原报告数值为 MAIN 65.35 倍、输入驱动 45.91 倍。先确认两边实际新增步数、完整终态和业务回执相等，再算逐对倍率的中位数及范围。每轮记录负载与实际库，MAIN 另记进程 CPU 秒。采样单独跑，不计入正式结果。

正式计时期间不运行其他 R3 计算任务。如果主机仍有其他重计算或明显 CPU 争用，报告只给有负载的复测值，不把它写成空闲机器下的精确复现。
