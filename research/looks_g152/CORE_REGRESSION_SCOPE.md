# 旧81组矩阵的延期理由

本轮未执行此旧全量矩阵。按用户的约两小时相关回归范围，使用最终格式和事务的专项验收，并另选10次旧用例执行（含 service-six-matrix）；本表逐组记录未跑范围，不把专项测试记成旧组通过。
