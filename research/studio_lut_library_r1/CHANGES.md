# LUT 库 R1 改动

## 库与文件

- 新增 `lut/library.py`，在应用数据的 `luts/library.json` 管理分组、名称、标星、输入空间、署名和版本。原文件以原始字节 SHA-256 命名，按 SHA 去重，旧版 SHA 文件自动登记。
- 新增 `lut/identify.py`，沿用关键词，按 33 点灰轴组合 known、guessed、unknown、conflict，保留两条依据，允许人工选择全部现有空间。
- 新增 `lut/metadata.py`，读取完整文件注释中的来源、作者和许可，包括数据行间、末尾和行内注释。原件导出保留全部字节，仅在 TITLE 需要清理时替换该行；更改署名时保留原注释，在头部增加当前字段，在末尾增加精确字段注释。
- 单个和分组导出到应用数据的 `luts/exports/<原文件 SHA>.cube`。未改动的文件保持原 SHA；TITLE 或署名变化时另算 SHA。表值、域、输入范围和 1D shaper 保持一致。
- 删除先提交库中的待完成记录，再标记配方来源和删除原文件。中途出错时，下次打开继续完成；生成的我的配方保留。
- 生成我的配方时保存来源署名；删除 LUT 前给旧配方补齐署名，再标记来源已删除。保存配方时持有库锁，空间改选不能插在版本核对和存储之间。

## 接口与成片

- 新增 `api/lut_library_routes.py`，提供库列表、LUT 更新与删除、分组管理、单个和分组导出。沿用原始字节上传接口，先检查格式与元数据文件名。
- 照片编辑与草稿增加 LUT SHA。`lut/photo.py` 接入 `finish.serve.color_image`，照片预览与成片导出共用同一阶段，调整在 LUT 后执行。
- 显示类 LUT 使用现有底图；Log 类读取 A12 50mm RAW 的场景 XYZ，全尺寸导出沿用 RAW 条带，缺少 RAW 或色彩矩阵时给出错误。
- 改选输入空间会递增版本、清空相关记录、使已完成的旧拟合不可再用，并停止正在运行的对应拟合。成片按当前库记录计算。
- 修正已使用过的缩略图和预览缓存：磁盘文件名及照片图片 URL 都带 LUT 身份与空间版本。空间改选和删除会得到新键，改名与标星不重画颜色。
- `lut/service.py` 和 `lut/worker.py` 的写入改用以应用数据为根的 `PrivateDir`，覆盖作业、取消标记、我的配方与清理。添加 `PrivateDir.names()`，按目录句柄枚举，不跟随子目录链接。

## 界面

- 「配方」页增加 LUT 库、分组与标星筛选、重命名、删除确认、署名字段和导出结果。
- 多选文件、选择文件夹和拖入文件夹均走顺序上传，显示每项结果，跳过系统元数据。文件夹读取持续到最后一批目录项。
- 照片的「配方」面板增加 LUT 选择；撤销、复原与导出前存储均包含这个选择。
- 名称用文本节点显示，署名草稿在改选空间或重新绘制时保留。复选框最小尺寸为 24px，其他控件沿用现有桌面样式。
- `dom.confirmAction()` 统一所有现有删除确认，涵盖 LUT、分组和我的配方。默认焦点为取消，回车不执行确认；按钮明确写删除，通用组件也核对替换按钮文字。
- LUT 缩略图和预览的缓存读写也用图库位置核对与 `PrivateDir`；已有缓存目录被改成指向图库以外的链接时同样拒绝。

## 文档与测试

- 更新 architecture、privacy 和 OpenAPI；没有增加功能开关或依赖，也没有改动锁定的 engine、spaces、校准或相机文件格式。
- 新增 `tests/test_lut_library.py`，LUT 和图像均现场生成；更新原编辑范围断言以包含电脑端 LUT。
- 新增 `tests/test_confirmation.py` 和标准 Node DOM 契约测试，核对取消焦点、回车行为和明确按钮文字；实际浏览器另测三个删除流程。
- `.gitignore` 增加 cube，用户及第三方 LUT 不进入公开仓库。
- 本目录保存检查脚本、逐轮日志、实际 pytest 收据、界面截图与版面数据。新增文案见 `COPY.md`。

本版没有写入存储卡、放进相机、3dl/Hald 转换、两档新预测、配方烘焙 cube 或分享码。

## 复审修复

- P1-01：采用原文件字节导出方案，未改动时不重新序列化 LUT；保留注释位置、空白、换行、BOM、数值文本和无末尾换行的文件。TITLE 清理保留同行注释。读取署名不再于第一条数据行结束。
- 已导入的旧库会补齐此前漏读的署名，字段与旧版文件头采集结果不同时保留用户修改；只升级署名记录，不递增颜色版本。
- P2-01、P2-02：后端提示统一使用「名称」；LUT、分组为 1–255 个字符，我的配方为 1–40 个字符。长度与无效控制字符分别报错。同步更新 COPY.md，以及相机配方文件目录项的同类用词。
- P2-03：`PrivateDir.replace_file()` 将创建及写入临时文件也包含在失败清理范围内，真实短写和文件同步失败均有回归。
- P2-04：空间为 12 种，设计中的 13 种为笔误，没有新增空间或改动锁定的 `spaces.py`。
- 新增 `tests/test_lut_review_fix.py`，覆盖三个复审原件的 SHA、实际 API 单个与分组往返、注释及字节保留、TITLE、署名编辑、旧库恢复、临时文件清理和各名称入口。
- 修正旧 `test_worker_result_files_and_parent_watch` 的隔离：`worker.run()` 的文件结果检查不再留下 4 个监测线程或改变 pytest 的信号处理；实际监测仍单独启动、等待退出，并新增无残留线程断言。真实子进程随父进程结束的测试保留。
- 前台检查脚本要求正常结束的 pytest 收据，缺少收据时即使进程返回 0 也判为检查未完成；另有返回 0 但不写收据的负例验证。
- 最终完整 `make check`：941 项通过，零重跑，覆盖率 92.547170%，高于被审 R1 的 92.475812%；私有字节检查通过 263 个文件。本轮具体源码文件及前后 SHA 见 `FIX_FILE_LIST.tsv`。
