DAT 格式

文件 generation 升为 124。第七段前 1,408 字节仍是原 GXTM v2、八参数、28 字节记录；后面追加固定 1,984 字节 GXUI v1。固定 resident 的外层格式和七段目录不变，第七段总长为 3,392 字节。

GXUI 的数值为大端。头部为 64 字节。

| 偏移 | 内容 |
| --- | --- |
| 0 | 七字符 `GXUI124` 加 NUL，共八字节 |
| 8 | u16 版本 1 |
| 10 | u16 头长 64 |
| 12 | u32 长度 1,984 |
| 16 | u32 整段 CRC，此四字节按 0 计算 |
| 20 | u16 配置数 24 |
| 22 | u16 配置记录长 48 |
| 24 | u16 有效用户条目数，0–32 |
| 26 | u16 用户记录长 24 |
| 28 | u16 全部项目数 11 |
| 30 | u16 用户容量 32 |
| 32 | u32 配置起点 64，相对 GXUI |
| 36 | u32 用户起点 1,216，相对 GXUI |
| 40、44、48 | 三个配方 bank 的 1,024 字节记录区 CRC |
| 52–63 | 保留，必须为 0 |

24 个配置按单元、底子排序，单元 0–2，各有底子 1–8。每记录 48 字节。

| 偏移 | 内容 |
| --- | --- |
| 0、1 | 单元、底子 |
| 2 | active order 长度，当前彩色为 4、03 为 3 |
| 3 | 保留 0 |
| 4–14 | 项目 ID 的显示顺序，未用字节为 0 |

当前四项的范围必须与旧 GXTM 对应参数相同。预留项的默认值均为 0。每条用户记录 24 字节。

| 偏移 | 内容 |
| --- | --- |
| 0 | 底子 1–8 |
| 1 | 保留 0 |
| 2–9 | 七字符生成名字加 NUL |
| 10–20 | 十一个有符号档位，顺序见上表 |
| 21 | 保留 0 |
| 22 | u16 组内序号 |

未使用的用户记录必须全零。条目需在三个单元的范围内都有效，未启用项目必须为默认值。相机只读取 resident 已装入的私有 DAT 副本，不为用户条目调用文件服务。

Mac 工具固定预留 32 条空间。用户条目数量变化不会改变文件长度、代码位置、重定位或 BSS 起点。它验证现有内层 CRC，重新生成用户段、配方绑定、载荷 CRC 和头部 CRC。

UI 与旋钮接入

当前彩色 order 为 `[1,2,3,4]`，03 为 `[1,2,3]`。`uv_window()` 接收逻辑行数、光标和旧窗口起点，输出八行窗口；19 行数值页和最多 33 行的用户列表共用这一函数。原生服务只允许八行，DISP 与方向键最终仍使用原入口表。

接入 knobs v2 时，需要在统一计算层转换十一档位并生成九行和 T，再更新 GXUI active order、范围验证和标签格式。放开 ±9 之前，需重新检查相邻档位是否不同、计算界限、补偿、安全反例与最终编译码。当前 `rt_tone/rt_saturation` 接口上限为 ±8，本轮没有用重复映射扩成 ±9。当前事务与确认账本仍使用八参数 `EngTweak`，四项由适配层映射；启用预留项时也要让账本保存十一项向量，不能只放开 active order。
