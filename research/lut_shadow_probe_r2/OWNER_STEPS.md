# 在相机上采集 LUT 影子耗时

本轮使用 r2 独立 DAT。先核对 [报告](REPORT.md)最终封存为“可以交复审”，再等待独立复审放行。只换测试卡上的 GXRCE.DAT，机身保持当前 v3.10 与 MOUNT。完整流程拍 13 张测试照片：L1 一张、L2 六张、L3 六张。某阶段失败就交已有结果，不继续凑张数。

每个编号只做一个动作。相机尚在保存、写灯亮或没有回到正常待机时，停在“等待”这一步。每张都先确认正常保存，再 arm 下一张。不要在保存中拔卡、强断电或换模块。

主机的确定性 tick 只验证记录、运算与退出。真实每张秒数只由现场两段校时录像和三对 OFF/ON 换算，不使用主机耗时。本轮把初始化拆成 17 片，每次 ADJ 重开推进一片；单片预算仍为 250 tick。17³ 表、Q8.8 内核和 L0 至 L3 预算均保持原样。

## 备好唯一 DAT 与原卡备份

1. 核对 [报告封存区](REPORT.md)的结论是“可以交复审”，并确认独立复审已经放行。
2. 记下本包 DAT 的完整 SHA-256。
3. 正常关闭相机。
4. 取出测试卡。
5. 把卡上原来的 GXRCE.DAT 备份到电脑的独立目录。
6. 记录原 DAT 的 SHA-256。
7. 把 [探针 DAT](../../firmware/package_v310_lutprobe_r2/local/SD_ROOT/GXRCE.DAT)复制到测试卡根目录。
8. 核对卡上新 DAT 的 SHA-256 与第 2 步相同。
9. 安全推出测试卡。
10. 将测试卡装回相机。
11. 开始一段手机录像。
12. 正常开机。
13. 等待相机回到正常待机。
14. 打开 Image Setting 的 ADJ 列表。
15. 拍下 `LP192 INIT SLICES` 的完整八行。
16. 停止这段手机录像。

录像保留开机到待机、第一次打开列表到 LP192 出现的等待，首次装载另算。此时只应完成初始化第一片，不能开始校时或拍摄。只出现原厂七行、没有 LP192，或出现错误时，停止试验并保留画面；七行本身不能说明具体拒绝原因。

继续沿用已认可的固定拍摄设置。试验中保持普通单张、12MP、相同曝光、ISO、WB 和存储格式。关闭连拍、包围和特殊场景。探针不会自动套用配方或修改这些设置。

## 完成 17 片初始化

第一次打开应看到 `LP192 INIT SLICES`、`BYTES 2048/29478`、`SLICES 1`，BUDGET 为 250，LAST 和 MAX 不超过 250。上下键只移动光标，不推进初始化。

每一轮只做以下动作。共做 16 轮，直到第 17 片完成。

1. 按一次 MENU/OK。
2. 等待正常待机。
3. 用 ADJ 重开 Image Setting。
4. 核对 SLICES 比上轮增加 1。
5. 核对 LAST 和 MAX 不超过 250。

前 15 片校验完整表，第 16 片跑私有内核自检，第 17 片跑空调用。第 15 片后 BYTES 为 29478。完成后页面自动变成 `L0 START TIME REF`，尚未开始计时，也没有 arm。不要为了等它自动前进一直留在页面上，未按重开动作时进度会停住。

若要在初始化中撤销，按一次 ADJ 退出。重开会显示 `LP192 INIT ABORTED`，BYTES 为 0。只有按 MENU/OK 后再次重开才会重新开始。确认退出保存的进度只在本次开机有效，正常关机后重做初始化。诊断页 INIT 是各片累计 tick，可以大于 250；单片上限看初始化页的 LAST 和 MAX。

`INIT FAILED`、`LOWER BOUND`、`SELFTEST FAIL`、`IRQ OFF` 或 `EPOCH CHANGED` 都停止本会话，拍下八行，不继续校时。

## 做第一段约 30 秒校时

主列表第 1 行是 `L0 START TIME REF`。以下“OK”与“MENU”都指相机同一个 MENU/OK 键，“向下”指列表向下键。两段都以约 30 秒为目标，尽量把间隔差控制在 1 秒以内；设备会拒绝原始 tick 区间相差超过 5% 的两段。录像中的实际秒数仍分别保留。

1. 选中 `L0 START TIME REF`。
2. 按一次 OK。
3. 开始手机录像。
4. 再次打开 Image Setting 的 ADJ 列表。
5. 等待 `LP192 L0 REF RUN` 页面出现。
6. 等待约 30 秒。
7. 按一次 OK。
8. 再次打开 Image Setting 的 ADJ 列表。
9. 拍下 `LP192 L0 REFERENCE 1` 的完整八行。
10. 停止手机录像。
11. 按一次 OK。
12. 再次打开 Image Setting 的 ADJ 列表。

保留按 ADJ 到 REF RUN 的过渡、约 30 秒区间及按 OK 的时点。分析时从录像量实际间隔，不能直接填 30.000 秒。页面里的 START、END 和 TICKS 都要保留。若超过软限时或按 ADJ 取消，当前段无效，停止试验并交画面。

## 做第二段约 30 秒校时

1. 选中 `L0 START TIME REF`。
2. 按一次 OK。
3. 开始第二段手机录像。
4. 再次打开 Image Setting 的 ADJ 列表。
5. 等待 `LP192 L0 REF RUN` 页面出现。
6. 等待约 30 秒。
7. 按一次 OK。
8. 再次打开 Image Setting 的 ADJ 列表。
9. 拍下 `LP192 L0 REFERENCE 2` 的完整八行。
10. 停止手机录像。
11. 确认末行是 `OK`。
12. 按一次 OK。
13. 再次打开 Image Setting 的 ADJ 列表。

`REF INVALID`、`IRQ OFF`、`SELFTEST FAIL` 或 `LOWER BOUND` 都不能晋级。两段有效后，第 1 行显示 `L0 TIME REFS DONE`。EMPTY64 为 0 可以正常出现，空调用可能不到一个 tick。

## 观察一张普通主图，L1

1. 选中 `L1 ARM OBSERVE`。
2. 按一次 OK。
3. 拍一张普通单张照片。
4. 等待相机完成正常保存并回到待机。
5. 打开 Image Setting 的 ADJ 列表。
6. 拍下 `LP192 L1 OBSERVE K0` 的完整八行。
7. 确认末行是 `OK`。
8. 确认 W、H、B 分别为 4288、2848、8576。
9. 按一次 OK。
10. 再次打开 Image Setting 的 ADJ 列表。

L1 不跑 LUT。页面里的 SP、HB、OUTER 与 SRC 是私有入口观察，照片只回传给实施者本地分析，不放公开仓库。SRC 是本张主图的地址值。HB 的 N 是本扩展块大小，不是空闲堆总量。

## 每次只增加一级行数，L2

按顺序完成下面六轮。每轮开始前先看主列表的 `L2 ARM ROWS`，它必须等于本轮行数。

| 轮次 | 菜单行数 | 结果页 P 必须是 | 软预算 tick |
| --- | ---: | ---: | ---: |
| 1 | 1 | 2144 | 250 |
| 2 | 4 | 8576 | 500 |
| 3 | 16 | 34304 | 1500 |
| 4 | 64 | 137216 | 4000 |
| 5 | 256 | 548864 | 12000 |
| 6 | 1024 | 2195456 | 45000 |

每一轮只按以下顺序操作一次。

1. 选中当前的 `L2 ARM ROWS`。
2. 按一次 OK。
3. 拍一张普通单张照片。
4. 等待相机完成正常保存并回到待机。
5. 打开 Image Setting 的 ADJ 列表。
6. 拍下本轮完整八行结果。
7. 确认末行是 `OK`。
8. 核对 P 与表中本轮数字相同。
9. 按一次 OK。
10. 再次打开 Image Setting 的 ADJ 列表。

L2 的 `PARTIAL` 表示设计上只算一部分行；只有末行 OK 且 P 完全相同才算本级完成。`LOWER BOUND` 表示没算完本级，停止后交已有结果。不要按部分行时间外推成已测整张。

## 拍三对 OFF 与 ON，L3 共六张

只有六轮 L2 全部通过才做本段。手机持续录像，画面保留按快门、相机屏幕、写灯和恢复待机的时点。

| 本段照片 | arm 时第 4 行必须显示 | 拍完的预期结果 |
| --- | --- | --- |
| 1 | `L3 ARM OFF 1` | OFF、OBSERVE、K0、末行 OK。 |
| 2 | `L3 ARM ON 2` | ON、P6106112 FULL、末行 OK。 |
| 3 | `L3 ARM OFF 3` | OFF、OBSERVE、K0、末行 OK。 |
| 4 | `L3 ARM ON 4` | ON、P6106112 FULL、末行 OK。 |
| 5 | `L3 ARM OFF 5` | OFF、OBSERVE、K0、末行 OK。 |
| 6 | `L3 ARM ON 6` | `LP192 L3 N6/6 OK` 汇总页。 |

每张都单独 arm，不能连拍六张，也不能用一次 arm 代替六次。

1. 开始手机录像。
2. 选中表中本张对应的 L3 行。
3. 按一次 OK。
4. 拍一张普通单张照片。
5. 等待相机完成正常保存并回到待机。
6. 打开 Image Setting 的 ADJ 列表。
7. 核对本张的预期结果。
8. 若不是第 6 张，按一次 OK。
9. 若不是第 6 张，再次打开 Image Setting 的 ADJ 列表。
10. 若不是第 6 张，回到第 2 步处理下一张。

任何 ON 没有 FULL、P 不是 6106112 或出现错误，立即停止本段。保留第一张错误画面和录像，不重新 arm 来覆盖失败。

## 拍一张汇总页并带回数据

1. 拍下 `LP192 L3 N6/6 OK` 的完整八行。
2. 停止手机录像。
3. 保留两个校时录像。
4. 保留 L1 和六级 L2 的结果照片。
5. 保留六张 L3 的拍摄顺序记录。

汇总页各行含义如下。

| 行 | 含义 |
| --- | --- |
| 1 | LP192、L3、六张样本完整通过。 |
| 2 | 两段参考区间的原始 tick，以及 64 次空调用的 tick。 |
| 3 至 5 | 三张 ON 的 K 与三组 D。K 是整段影子窗口，含检查和校验；D 是本对 ON 减 OFF 的 H40 到 H41 增量，可以为负数。 |
| 6 至 7 | 三张 ON 的校验值 C1、C2、C3，以及每张 ON 的 6,106,112 对。 |
| 8 | 六个原始状态字，按 OFF/ON 一对、OFF/ON 一对、OFF/ON 一对排列。每个为四位十六进制，非零值本身不代表保存失败。 |

每张拍完后立即拍下它的原始页，不依赖上下键浏览历史。主列表 RESULTS 可重看最近一张。原始页 A、B 是 H40 与 H41，KS、KE 是影子窗口起止 tick，S 是原始状态字。OK 表示探针记录完整，保存是否正常以相机和照片为准。原始页不代替最终八行汇总照片。

H41 不表示写卡全部结束。录像里的保存等待单独量，不能直接把 D 称为“总保存时间”。

## 遇到这些画面就停止

| 画面 | 含义与本轮动作 |
| --- | --- |
| `ARM EXPIRED` 或 `CANCELLED` | arm 过期或已取消。本张没有获得有效测速，不把旧结果算新样本。 |
| `GEOMETRY` | 当前路径或主图不在准入范围。保留 L1 或错误页。 |
| `LOWER BOUND` | 单片初始化或本帧软预算用尽。只交已算对数和实测区间。 |
| `INIT ABORTED` | 初始化已撤销，进度归零；MENU/OK 明确重启后才可继续。 |
| `INIT FAILED` | 初始化锁住，拍下八行并停止本会话。 |
| `EPOCH CHANGED` | 会话身份或模式发生变化。保留首错。 |
| `IRQ OFF`、`BAD TICK` 或 `REF INVALID` | 时基门没有通过。不要换算秒数。 |
| `ENC WORD UNKNOWN`、`MISSING H41` 或 `REENTRY` | 原始字超出已核对范围，或返回链没有成立。不要继续本会话。 |
| `SELFTEST FAIL` 或 `BUFFER GUARD` | 私有计算或缓冲边界未通过。不要继续本会话。 |
| 原厂七行且没有 LP192 | 探针没有正常接管该列表，或尚未完成加载。只在保存结束后记录画面，不继续阶段测试。 |

## 换回原配方 DAT

1. 等待相机恢复正常待机。
2. 正常关闭相机。
3. 取出测试卡。
4. 将第一个阶段备份的原 DAT 复制回卡根目录。
5. 核对恢复后的 SHA-256 与原 DAT 记录相同。
6. 安全推出测试卡。
7. 将测试卡装回相机。
8. 正常开机。
9. 等待相机恢复正常待机。
10. 打开原配方列表。
11. 拍下已恢复的 g157 test 或获准 g158 页面。

探针没有写 IROM 或设置，恢复的是 DAT；原配方的正常开机应用逻辑随原 DAT 恢复。若相机没有回到正常待机，停止换卡步骤并保留现象，不靠存图中拔卡或强断电来试错。
