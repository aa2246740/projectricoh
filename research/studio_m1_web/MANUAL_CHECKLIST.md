# GXR 电脑工作室 M1 · 浏览器手动检查清单

用途：人在浏览器里逐项核对界面。自动化部分见 `studio/tests/test_web_smoke.py`；
浏览器走查脚本见 `browser_walkthrough.mjs`（只覆盖下面标 ★ 的部分）。

## 0. 准备（只用假卡）

**不要**把 `GXR_STUDIO_VOLUMES` 指向 `/Volumes/RICOHDCX` 或其他真实挂载的卡。

```bash
cd studio
rm -rf /tmp/gxr-check && mkdir -p /tmp/gxr-check/vol /tmp/gxr-check/lib /tmp/gxr-check/exp
uv run python -m gxr_studio.devtools.synthetic_card /tmp/gxr-check/vol      # 带 4 对真实样本（约 90 MB）
GXR_STUDIO_VOLUMES=/tmp/gxr-check/vol GXR_STUDIO_LIBRARY=/tmp/gxr-check/lib \
GXR_STUDIO_EXPORT=/tmp/gxr-check/exp GXR_STUDIO_TOKEN=check123 \
uv run gxr-studio --no-browser --port 8790
```

浏览器打开 `http://127.0.0.1:8790/?token=check123`。
检查前后记下卡的内容：`find /tmp/gxr-check/vol -type f -exec shasum -a 256 {} + > /tmp/gxr-check/card-before.txt`。

## 1. 第一次打开（新浏览器配置文件）

- [ ] ★ 弹出三张引导卡，标题依次是「插上卡，照片自动进来」「点一张，裁一裁」「调好了，导出 JPEG」。
- [ ] 「上一步」「下一步」能用，最后一步按钮是「开始使用」。
- [ ] 「跳过」关掉后，刷新页面不再弹出。
- [ ] `?` →「重看新手引导」能再打开。

## 2. 插卡导入

- [ ] ★ 卡插上后横幅出现「发现相机卡 · 正在导入 X/Y 张 · 只读复制，卡上的照片不会被改动。」
- [ ] 横幅有「取消导入」，点后显示「已取消导入。已导入的 … 张照片保留着。」
- [ ] ★ 完成后横幅写明「新增 A 张，跳过 B 张，C 张读不出来」，末尾是「现在可以安全弹出卡了」。
      （A、B、C 要和 `GET /api/jobs/<id>` 返回的 `imported_shots`、`seen_shots + duplicate_shots`、`unreadable` 对得上。）
- [ ] 完成横幅的「知道了」能关掉。
- [ ] 状态栏：导入中显示「卡：正在导入 X/Y，先别拔卡」，完成后「卡：导入完成，可以安全弹出卡了（在访达里点弹出）」。
- [ ] 同一张卡再次插入（或刷新页面），横幅是「这张卡上的照片都导入过了。」，且有「知道了」。
- [ ] 导入中拔卡（删掉卡目录模拟）：横幅变红，写「导入被打断了…插回卡可以继续。」；插回后出现「继续导入」，只补缺的。（这项只能在有真卡或模拟时核对。）
- [ ] 没有卡、也没有导入过的时候，页面不出现「发现相机卡」横幅。

## 3. 图库

- [ ] ★ 左侧「全部」和每个日期的数量正确；未知日期排在最后（有未知日期时）。
- [ ] ★ 点日期只显示当天的照片，右上标题是日期。
- [ ] ★ 角标三种都有：「DNG+JPG」（绿色边）、「只有 JPG」「只有 DNG」（灰字）。这三个是提示，不是错误。
- [ ] 日期是按文件时间估计的照片，悬停提示里写着「日期是按文件时间估计的」。
- [ ] ★ 左上角勾选框能多选；底部出现「已选 N 张」「导出选中的」「取消选择」。
- [ ] 「取消选择」清空选中。
- [ ] 空库（没有卡、没有照片）：显示「还没有照片」，「我怎么插卡？」展开三步。
- [ ] 卡上都导入过了、库里有照片：不显示空状态。

## 4. 大图

- [ ] ★ 点缩略图进入大图，顶栏显示名字、时间、日期、角标；右上角「1 / 15」这样的序号。
- [ ] ★ ← / → 切换上一张、下一张；第一张的「上一张」和最后一张的「下一张」是灰的。
- [ ] ★ 按住 Space 隐藏裁切框（看原图），松开恢复。
- [ ] ★ Esc 回到图库；有弹窗时 Esc 先关弹窗。
- [ ] C / R / A / E 切换右侧标签（裁切 / 配方 / 调整 / 导出）。
- [ ] 第一次看到某个标签的时候，顶部出现一句小字提示；点「✕」后以后不再出现。

## 5. 裁切

- [ ] ★ 比例按钮：原比例、3:2、4:3、1:1、4:5、16:9、XPan 65:24、自由。选中的按钮是金色边。
- [ ] ★ 选比例后，框立刻出现，默认居中，「当前：…，裁出 W × H 像素」数字正确。
- [ ] ★ XPan 65:24 在 4288×2848 的照片上裁出 4288 × 1583 像素（真实样本）。
- [ ] ★ 拖动框：框的位置跟着鼠标走，松手后刷新页面位置还在；框不会被拖出画面外（夹在边界上）。
- [ ] 框的大小滑块能缩小（最小 30%），缩小后框仍在原来的中心附近。
- [ ] ★ 拉直滑块：−10° 到 +10°，画面跟着转，框留在原位置；松手后保存。
- [ ] 双击拉直滑块回到 0°。
- [ ] ★ ↑ / ↓ 每次拉直 0.5°。
- [ ] 把框拉到超出画面（比如拉到很大的角度而框没缩小）：出现提示「拉直之后裁切框超出了画面，请缩小一点或挪一挪」，画面回到上一次保存的样子。
- [ ] ★ 「还原裁切」去掉裁切；「还原原图」效果相同。
- [ ] ★ ⌘Z 撤销上一步裁切；连续撤销直到没有可撤的，提示「没有可以撤销的了」。
- [ ] 16:9 的照片（相机 16:9 拍的，假卡里没有）：出现「这张是 16:9，要裁成 XPan 65:24 吗？」，点「裁成 XPan」生效。原图不会被改。
- [ ] 裁切只写进旁边的说明文件：原照片的哈希前后不变（见第 0 节的哈希记录）。
- [ ] 「完成」提示「已记下：…」或「没有裁切，原图不变」。

## 6. 导出

- [ ] ★ 导出标签：范围（这一张）、尺寸（原始、长边 3000 / 2048 / 1600）、质量滑块（60–100，显示「高 / 中 / 低」）、存到（默认导出文件夹，可以改成完整路径）。
- [ ] ★ 导出一张：结果写「导出完成。」和完整路径，尺寸和文件大小正确；文件名是「原名_gxr.jpg」。
- [ ] 同一张再导出一次：文件名变成「…_gxr-2.jpg」，不覆盖。
- [ ] 存到写了相对路径（比如 `exports`）：提示「导出文件夹要写完整路径」。
- [ ] ★ 只有 RAW 的照片：导出标签显示「这张只有 RAW（DNG），暂时不能导出。导出需要配对的 JPG…」，「开始导出」是灰的。
- [ ] ★ 多选里混有只有 RAW 的：显示「其中 N 张只有 RAW…会跳过」；导出后结果写「导出完成：X 张 JPEG 已保存。Y 张没有导出：…」。
- [ ] 尺寸按钮（长边 3000 等）只放大不超过原图：小图导出后尺寸不会变大。
- [ ] ⌘E 在大图里切到导出标签；在图库里有选中时打开「导出选中的」弹窗；都没有时提示「先在图库里勾选要导出的照片，或打开一张大图。」

## 7. 配方、调整、相机（占位）

- [ ] 顶部「配方」旁边有「即将推出」。点进去是「即将推出（M2）」说明页。
- [ ] 大图的「配方」标签显示 8 个底子的名字，标「即将推出」。
- [ ] 「调整」标签写明「只在电脑上生效，不会写进相机」，标「即将推出」。
- [ ] 「相机」页写明「这一版不会往卡上写任何东西，卡上的照片只读」。
- [ ] 全部界面文字里没有「固件」「寄存器」「刷入」等词（帮助页和本清单除外）。

## 8. 设置与帮助

- [ ] ★ ⌘, 或顶部「设置」打开：显示照片库、导出文件夹、照片数、剩余空间；「重建照片索引」能用，成功后提示「索引已重建：N 张照片」。
- [ ] ★ `?` 或顶部「?」打开快捷键表，内容与 UX.md §7 一致：← →、Space、Enter、Esc、C R A E、↑ ↓、⌘Z、⌘E、⌘,、?。
- [ ] 设置里的存放位置说明写着：要改位置需要重新启动并设置环境变量。

## 9. 离线与卡只读

- [ ] ★ 浏览器开发者工具「网络」：所有请求都是 `127.0.0.1`，没有外部地址。
- [ ] ★ 导入、裁切、导出全部走完后，第 0 节的哈希与记录一致：`shasum -a 256 -c` 通过，卡上没有新增、删除或修改的文件。
- [ ] 不带 token 直接访问 `http://127.0.0.1:8790/` 或 `/api/cards`：拒绝（401）。

## 10. 已知限制（不算缺陷，但要知道）

- 「安全弹出卡」在 M1 没有按钮（后端没有弹出接口）；界面只写文字说明，要在访达里弹出。
- 自由比例只能拖动和缩放，不能拖动四个角改形状。
- 拉直之后，框画在画面坐标上，图片转在框下面；角上的空白是正常的，框不会越过原图（后端会拒绝）。
- 「看原图」只是隐藏裁切框（M1 还没有调整，所以原图和当前画面一样）。
- 导出文件夹是手动输入的完整路径（浏览器不能直接选文件夹）。
- 缩略图和大图在 DNG 上用的是相机内嵌的 JPEG 预览，不是 RAW 解码。
