## 松下模型的证据与边界

管线为 GXR DNG、沿用 camera.py 的固定中灰锚与逐帧 DNG 矩阵转场景 XYZ、官方 V-Gamut/V-Log 编码、有界反演至松下 Standard 显示 RGB、胡子 LUT、显示 RGB 浓度混合。没有为不同 LUT 自动调整曝光或白平衡。

V-Log 系数与 V-Gamut 原色沿用 `research/lut_convert/spaces.py`，并对照 [Panasonic 官方参考手册](https://pro-av.panasonic.net/en/cinema_camera_varicam_eva/support/pdf/VARICAM_V-Log_V-Gamut.pdf) 的 §3–4；黑、18% 灰、90% 白的 10 bit 编码复核及矩阵误差见 `local/inverse_anchor_evaluation.json`。

## 拟合口径

训练集 1008 点、合成留出 1970 点。额外灰轴在训练中权重为 4；测试使用另一组灰阶，并剔除夹紧后重复的 1 个黑点，精确共用输入为 0。合成 XYZ 沿用第一张 DNG 的白平衡和矩阵，不代表任意照明的传感器匹配。
每张实景从 RAW 未裁切位置均匀抽取 3000 个像素评分，全图参与预览。第一张仅借用 DNG 元数据构造合成 XYZ，没有任何实景像素用于拟合。

相似度严格使用既有定义 `1 - median(配方到目标 ΔE00) / median(原厂04到目标 ΔE00)`。它衡量消除了多少原厂 04 到目标的差距，不是与松下、徕卡或真实照片的绝对还原率。分母小于 0.25 时不定义。松下基底版本包含从 04 改到松下基底的差距，不能把两种基底的百分比直接排名。

70% 浓度定义为显示编码 RGB 的 `0.3 × 基底 + 0.7 × LUT(基底)`，全浓度为 100%。这是普通显示参考 LUT 的交叉混合定义，符合“减弱造型、保留基底”的要求；胡子未公开其 App 浓度算法，不能声称完全复刻了该滑杆，也没有把它解释为场景线性混合。

safe 仅使用共同曲线、Y 矩阵行与 24 个对称扇区，不用 T/C/D；T1 增加 R=C、G=B5、B=D 三通道曲线并启用 T 控制。所有分数都在整数化曲线、矩阵和扇区之后重算。safe 的“日常”只指旋钮类型，每份候选仍为 `daily_eligible=false`、`camera_acceptance=false`。
本次未搜索独立色度矩阵、四个自由 C/D 扇区或 D8 节点移动；结果是既有转换器范围内的近似，不代表 GXR 所有配方控制的色彩上限。

## 产出与复核命令

- `local/prepared/` 保存十个反演基底、原像残差、边界统计、机型两两差异与全部整景样本。
- `local/fits/<LUT>/<基底>/p100或p70/safe或t1/` 保存 56 组指标、各 24 行扇区残差、限制说明、四列预览、448 B 单条深层条目、49 B 模板身份及其 CRC。
- `local/best_candidates/` 保存 7 个优先比较候选；它们没有表头、卡文件或安装入口。49 B 身份仍绑定转换器 slot 05 模板，后续组表须重新绑定名称、原生模式和 recipe CRC。
- `local/SUMMARY.csv`、`local/SUMMARY.json` 提供汇总；`local/verification.json` 提供最终独立条目回放、输入不变与范围检查。
- `local/diagnostics/` 保留首次灰轴交叉及色域面反演问题的原始记录；各脚本日志保留在 local/。`SHA256SUMS` 覆盖本任务所有最终普通文件，排除自身。

```bash
cd /Volumes/Workspace/Projects/T3-Runtime/projects/projectricoh
python3 -I -B research/huzi_luts/acquire.py
python3 -I -B research/huzi_luts/prepare.py
python3 -I -B research/huzi_luts/audit_inverse.py
python3 -I -B research/huzi_luts/fit_luts.py --max-nfev 120
python3 -I -B research/huzi_luts/deliver.py
python3 -I -B research/huzi_luts/verify.py
git check-ignore -v research/huzi_luts/local/best_candidates/INDEX.json
cd research/huzi_luts
shasum -a 256 -c SHA256SUMS
```
