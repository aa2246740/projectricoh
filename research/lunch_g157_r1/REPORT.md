广告牌中的 Kodachrome 25 为 49.1% / -5.8%。跨目标各有不同的 04 分母，不能凭这张表的百分比给不同风格排总榜。film_looks_r2 报告中的 Kodachrome 25 Look 64.33%、满配 76.81%，来自重新拟合记录及旧留出，不是当前这条 g157 记录在新场景中的承诺。

本轮只评价既定目标的颜色与明暗，不评价胶片颗粒、光晕或真实宽容度。没有第一名响应的 g157 项不报实拍相似度，包括 07、08、Tri-X 400、Metropolis、ARRI 709、Eterna BB、RED IPP2 及三个用户项的独立身份；默认用户项与 05 的等价关系已单列。

## 异常

55 张中没有留出中位 >5 或 p95 >10 的整张明显偏离；这不是相机所有功能的验收。需要保留的局部异常为 R8052093 的 06 F-CN。它的整体中位 / p95 为 1.21/2.89，蓝色域 194 块为 2.99/4.44；实际蓝色域的 Lab a* 较预测低 2.28、b* 低 0.94。它更符合现有模型在蓝色域的局部残差，照片本身不能唯一归因到相机。

对首张 04、06 及较大残差的 Kodachrome 25 共 7 张做了独立诊断。把 RAW 横向位移改为 −2 或 0，不能明显消掉 06 的误差；把曲线、矩阵或扇区分别换成 04，也没有得到更接近该张 JPEG 的“少写一部分”解释。所有诊断只作对照，没有据此重选位移、曝光、白平衡或主评分。

早上 11 张均能识别，合并误差 0.46 / 1.41，未见与 P/A/S 切换同时出现的整套颜色失配。不同模式下用的配方不同，不能据此比较模式优劣。03 HC BW 与 Acros 对相机的误差都约 0.10；03 HC BW 对既定目标的相似度仍只有 30.9%，这是风格目标差距。

机主报告全程没有 ERR、Unsaved 或列表消失。照片支持颜色输出连贯，但没有记录菜单或 BOOT 内部状态，不能代替这些状态的实机日志。

## 对配方或模型的改进建议

1. 先统一 Kodachrome 25 的产品目标。若要维持现有明亮的 g157 观感，就按原目标管理；若要接近 film_r2 的场景光目标，优先重做中间调响应并核对黄、青色。不要把两种目标的成绩混成一个百分比。
2. 以场景光目标做新的满配候选，再用新场景验证。现有 24 张保留为评估集，不一边改参数一边把它们当新留出；优先改善中间调，保留这次已经接近目标的暗部。旧满配模型分数不能代替新候选实拍。
3. 模型优先补 06 的蓝色域与偏色中性色。后续最小补拍可在同一稳定光源、ISO200、固定 WB 下做 04→06→04，并纳入同一蓝色和灰阶对象，区分输入映射、空间处理与配方响应；本轮不改相机或 DAT。
4. 下一次切换配方时留一份本地顺序记录。05 和默认 FCC-001 需要菜单记录才能区分；Kodachrome/HNCS LowSat、千禧 A/B 等近似风格保留分差，补拍时增加能拉开它们的颜色，避免按记忆硬认。

## 方法、证据与复跑

输入为 57 对 JPG+DNG，其中午间 44 对、早上 11 对、昨天 2 对仅核验完整性。DAT SHA-256 为 `2b8904592ce56ab03649ced52c8479b0bbac4e45bf9a47505d220795bb3ec56c`。使用实际 MOUNT 记录、原生 C040 加既有实测偏移，以及 model_c040_r1 重建的 RAW→04 输入映射，没有用 legacy50。55 张均为 ISO200；午间全部 M/Auto WB，早上 Manual WB，含 M/P/A/S。没有逐照片拟合曝光或白平衡，也没有给未知 WB 补偿填 0。

从每张原分辨率照片固定采 96×72 个位置，每块 12×12 像素，RAW 与 JPEG 固定横移 −1 像素。沿用平滑块条件，排除 RAW ≥0.98、RAW ≤0.002、JPEG 极端码值和 L* 在 10 至 95 之外的区域；识别只用 4×4 空间分区的偶数半区，误差和风格评分只用奇数半区。各候选用完全相同的掩码。旧掩码的逐配方对照保存在 summary.json，未按误差删点。

每张均保存 29 个候选的本地预测 JPEG，共 1,595 张。定量比较采用解码后实际 JPEG 的平滑块均值和未二次压缩的模型 RGB；256 像素 JPEG 只是本地颜色预览，不模拟 demosaic、锐化、降噪或 JPEG 空间 ISP，也不参与定量评分。主结果按有效块合并；逐照片统计另存，空间抽样胜率不当作跨场景的统计置信度。

最终复核重读 114 个原始照片文件，SHA-256、大小和修改时间均未变，DAT 未变；38 个模型输入文件未漂移。独立曲线 / 矩阵 / C080 字面方程重放全部 55 张，最大 RGB 差 5.68e-14 code；还用既有冻结缓存重放两种胶片目标及黑白目标，确认目标解释一致。

核验首错保留在 local/queues/verify-*/verify-0.log。首次目标缓存复核把“冻结旧目标”的旧 04 输入误换成 base_new，出现 30.38 code 差；按原缓存契约改回 base 后通过，本批照片的目标评分没有因这次核验修正而改变。新增色域汇总时一次局部变量覆盖了配方名，已修正并重算汇总；旧汇总与日志留在 local/history/ 和 queues/。

计算均为隔离 Python `-I -B`、nice 15、数学库单线程。队列用 `tools/loadgate.py` 的 `cap(len(running))`，独立作业用 `workers()`；没有另设 load1 门槛。没有访问网络、相机或 SD 卡，没有安装依赖、commit 或 push。照片及派生图均在被忽略的 local/。
