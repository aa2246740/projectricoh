## 06 蓝色残差：原生C040修正已经生效，尚不能唯一归因C040或C080

本节模型对相机JPEG的残差沿用R1的D50口径，前表记录对风格目标的相似度采用D65，两种分数没有混算。

R8052093 蓝色域仍为中位 / p95 ΔE00 2.99 / 4.44。当前模型的 24 个 C040 节点与 model_c040_r1 的 MOUNT 原生节点逐值相同；再次套用同一个节点修正不会改变输出。剩余角向核、k 耦合与 gain 仍来自 50mm 标定，是明确需要验证的 MOUNT 响应环节。C080 记录字节没有被证明错误，未闭合的是 C040、曲线、C100、C080 和输入映射的组合响应。

这张蓝色域进入查表前的色度中位只有 3.89 code，色相中位为 38.3°。照片内容中的“蓝色”并不等于 C040 的某个蓝色节点；06 的曲线与矩阵已经改变了查表入口。低色度处的输入误差、角向模糊和量化会相互影响。

对失败区域的查表入口作了覆盖核对。其 5% 至 95% 矩形为色相 24.61° 至 52.47°、色度 3.55 至 4.15 code，矩形只用于统计数据覆盖，没有估计参数。受控 noon 的 06 T/V/色卡在这个窄区域中分别为 0 / 0 / 0 点；扩展到色相额外 ±15°、色度额外 ±2 code 后，分别只有 0 / 2 / 1 点。Probe2/3 的扩展区域仍均为 0 点。

若继续 model_c040_r1 这条研究路线，应先利用已有的原厂04标定、noon T页、实体色卡与上述有身份的历史RAW，按实际查表入口而非“蓝色物体”标签整理样本。先核对 RAW→04，再研究受约束的 MOUNT 低色度角向核 / 增益残差，保留 V 页和整场景作独立验证。要把 C040 经验残差与 C080 响应单独拆开，仍需要足够的独立色相、色度和变换方向；当前受控数据在失败入口附近稀少。现库能启动这项研究，现阶段不能承诺一个唯一修复项。本轮没有拟合任何新模型，也没有索取补拍。今天55张始终只作评估。

## 输入、复核与复跑

满配胶片来自 `film_looks_r2/local/full_library_manifest.json`；官方 Acros 来自 `acros_official_handoff.json`。Eterna BB、Leica Classic 的两个位置和数字风格对照来自该研究的 `style_analysis/*/mount-a12.json`。六个锁定 Look 使用 `locked_shared_flags7_handoff.json` 的共享RGB曲线记录，保持其默认响应等价；没有从 g157 取候选字节。g157 的原厂04仅作固定模型锚点，g157的实际JPEG仅用于上一轮残差和Kodachrome区域对照。

保留每条记录的原路径、SHA、旧分数、固定目标与选定路线，未改变配方字节、曲线、矩阵、扇区、目标曝光或WB。主模型仍为原生 MOUNT C040，加 model_c040_r1 的输入映射；55张全部ISO200，均用各自DNG的WB和场景矩阵。没有 legacy50，没有逐照片曝光或WB拟合。

主取样逐式复用 `recipe_redo_r1/prepare_inputs.py::sample`：32点宽、2×2 CFA、排除RAW裁切、每张最多96点。旧留出也按原来的整数输出 `np.rint` 评分，04分母保持连续预测。额外严格筛选排除 RAW≤0.002 和场景 L* 不在10至95的点；R1固定平滑块还排除原JPEG极端值、过暗过亮和纹理变化。所有掩码在候选误差计算前确定，没有按误差删点。

独立复核重读114个照片原件，SHA、大小、修改时间均未变；DAT未变。54条记录共重放 356,400 个输入点，独立字面方程最大RGB差为 5.68e-14 code。每条记录的原目标旧留出分数均重算吻合，另用独立场景输入路径核对三个改口径的数字目标。今天的55张与之前的输入照片没有哈希重叠。

库检索的首次查询只在DNG上找标签，漏掉了挂在JPEG上的标签；已改为按配对合并两侧，旧结果留在 local/r2/history/。源照片、索引和记录均只读，索引查询使用本地只读快照。其它首轮I/O、负载延后与回执原样保留。
