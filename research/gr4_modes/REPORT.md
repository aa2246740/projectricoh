# GR IV 正片、负片、高对比黑白：相对 Standard、相对 RAW，以及搬到 GXR

2026-10-19。数据有三部分。两位投稿人的 GR IV：A 是 fw 1.11，三个不同场景；B 是 GR IV HDF fw 1.10，滤镜关，同一场景、同一曝光连拍了 Standard、正片、负片、高对比黑白、电影黄、电影绿。另有论坛公开的 GR IV / GR III Standard 样张，以及 bastibe 的 GR III 色卡。全程只读，没有写固件，没碰 /Volumes，没有 git commit。投稿照片派生出的数组、缩略图和候选行都只放在 `local/`（已 gitignore）。

## 结论
1. **高对比黑白的曲线是固定的，和 GXR row 20 差很多。** 两台机身、两个场景、DR 开和关，曲线在重叠段只差 1–3 码。以 GR IV Standard 出 118 的曝光为 0 EV，各档输出是：−2 EV 出 7，−1 EV 出 24，−0.5 EV 出 47，0 EV 出 96，+0.5 EV 出 173，+1 EV 出 223，+1.5 EV 出 242。从 50 到 200 只用 1.15 EV，最陡处约 166 码/EV。row 20 的 128 在 +1.0 EV，GR IV 的 128 在 +0.22 EV，相当于 row 20 要多约 0.75 EV 的光。row 20 的趾部也更亮：−3 EV 出 6.7，GR IV 出 2。
2. **黑白的通道混合不是亮度。** 在白平衡后的相机 RGB 上，GR IV ≈ 0.50 R + 0.08 G + 0.42 B，折成线性 sRGB 权重是 0.32 / 0.30 / 0.38，接近 R、G、B 等权。GR IV 单色、GR III 单色和两张高对比黑白给出的是同一组数。GXR 真黑白在 stage2d 色卡上是 0.21 / 0.53 / 0.26。换成 GR IV 的混合，GXR 色卡上的绿会暗约 0.45 EV，红和品红亮约 0.37 EV，蓝亮约 0.28 EV。type-26 曲线改不了混合。
3. **高对比黑白有颗粒，没有局部对比。** 中间调多出约 17 码 RAW 里没有的噪声（全分辨率高通标准差）。ISO 100 和 ISO 320 一样大，每张不同，相关长度约 2 像素。其他模式和单色只有约 1 码。残差和 32–1024 像素尺度的周围亮度无关：单项 R² ≤ 0.002，全部合起来 ≤ 0.004。所有模式共用同一条径向暗角补偿，角上约 +1.1 EV。
4. **03 的 GR IV 候选行在 `local/candidates.json`**（`modes.hc_bw.row_jpeg_domain`）。方法同 phase 1：在 JPEG 码域把「高对比黑白相对 Standard」套到 stock row 5 上。stage2d 六级灰 D6–D1 预测为 3 / 15 / 67 / 210 / 243 / 249，row 20 是 8 / 12 / 29 / 93 / 180 / 220。主要不确定度在 GXR 的测光中灰：偏 ±0.15 EV 时，D4 落在 54–84，D3 落在 189–218。
5. **正片、负片的滑杆就是预设默认值**（推断，证据强）。GR III 1.60/1.71、GR IV 1.11、GR IV HDF 1.10 三台机身记录的值完全相同：正片是 −1 / +3 / −1 / −2，负片是 +1 / +1 / 0 / −1。所以这里量到的就是默认阶调，不需要从滑杆反推。
6. **正片、负片的阶调，两代只差几码。** 在 GXR 六级灰上，GR IV 版 01 比现行 GR III 版亮 1–3 码，D1 暗 0.8 码。GR IV 版 02 在 D4–D2 暗 3–4 码，D1 暗 7 码。两台 GR IV 之间的正片本身就差 1–7 码。01 不必为阶调换版。02 的高光要先排除 DR 的影响，因为两张 GR IV 负片都开了 DR 扩展。
7. **色彩上，负片两代一致，正片不一致。** 负片色度比相差 ≤ 0.14，色相相差 ≤ 8°。正片在黄、黄绿、青上不同：GR IV 的黄色度不降、转 −9.5°，GR III 降到 0.77、转 −2.7°；青 GR IV 转 +19°，GR III 只转 +3°。橙、肤色、绿两代接近。红、品红、蓝、紫没有可用的 GR IV 样本。这和固件结论吻合：负片矩阵两代逐字节相同，GR IV 正片改了矩阵，另有 MultiAxial。
8. **负片灰轴没有分色。** 中性的 a\*b\* 和 Standard 相差在 1 以内，暗部和高光不变号。负片做的是去饱和，高光去得更多（中性附近色度增益从 L\* 20–30 的 0.79 降到 L\* 80–90 的 0.30；Standard 是 1.06 到 0.56），外加绿、红、青的色相转动。这和富士 Classic Neg. 那种暗部、高光分开着色是两种做法。
9. **还缺两样**：一张带色卡和深灰阶的 DNG 在机内显像成四种模式（最少 1 DNG + 4 JPEG），以及 GXR 测光中灰的实测。

## 0. 证据分级
已验证：读了文件、像素或元数据，文中的数就是读到的。推断：依赖一个写明的模型或假设，例如 GXR 中灰在 u = 320、JPEG 码域转移。未知：现有数据回答不了。

## 1. 读法和 u 的定义（已验证）
所有文件都用 `RICOH\0II` 格式的 DNGPrivateData。`0x004f`：A 是 261 / 262 / 267，B 是 256 / 262 / 267 / 261 / 268 / 269。DNG 和 JPEG 的 MakerNote 一致。

EXIF 和简报有出入：A 的高对比黑白和正片 ExposureProgram 是 4，负片是 3；B 六张都是 1，简报说的是 P 档。B 六张都是 1/10、f/2.8、ISO 320，AsShotNeutral 相差不到 0.6%。A 的 SensitivityType 是 1（SOS）。

DNG 是 14 位，BlackLevel 64，WhiteLevel 16317/16318，ActiveArea 是 (34, 26, 4194, 6250)，DefaultCropOrigin 是 (28, 24)，所以裁切从 (54, 58) 起，大小 6192×4128，RGGB，和 JPEG 同尺寸。没有 OpcodeList。BaselineExposure 在 DR 关时是 −0.506，DR 开时是 +0.488 到 +0.494。JPEG 是 4:2:2。RAW 和 JPEG 在 35 个块上的位移都在 0.05 个半像素以内，没有畸变校正。

```text
c   = (raw − 64)/(White − 64)，RGGB 四元组，G 取两绿平均
u   = 2^BaselineExposure · (cR/nR + 2cG/nG + cB/nB)/4，n = AsShotNeutral
u_c = u · g(r)，g(0) = 1
JPEG 亮度 = 编码 RGB 的 Rec.709 加权
```

**径向增益**（推断为暗角补偿）：r = 0.5 / 0.7 / 0.85 / 1.0 处分别是 +0.23 / +0.48 / +0.75 / +1.13 EV。15 张 GR IV 各自拟合，到 r = 0.85 彼此差约 0.05 EV，最角上差到约 0.2 EV。光圈覆盖 f/2.8 到 f/14，所有模式都是这条曲线。高对比黑白没有另加暗角。

**GR IV Standard 的 118 点**：B 是 u_c = 0.0853。论坛 GR IV（fw 1.02，DR 关，6 张）是 0.0843–0.0872，中位约 0.0863。DR 开的 B 和 DR 关的论坛帧，在 −2.5 到 +1 EV 上相差 0.1–1.5 码。论坛里 fw 1.02、ISO 2000–3200、DR 开的几张例外，0 EV 暗约 5 码，没有采用。GR III Standard 的 118 点是 0.0816–0.0871（色卡帧 0.0858）。

## 5. 色彩
### 5.1 方法
场景色的算法是：相机 RGB 经 DNG ColorMatrix（按 CCT 插值，AsShotNeutral 映到 D50），乘 2^BE 和径向增益，再把 Standard 118 定为 L\* = 50。

- **相对 Standard（B）**：几张是手持拍的，所以不做像素配准，而是通过 RAW 分箱匹配。分箱维度是场景色相（每 15°）× 色度（6–12 / 12–25 / >25）× L\*（<35 / 35–60 / 60–80 / >80），每箱比较 JPEG Lab 的中位数。
- **相对 RAW**：把场景 XYZ 缩放到 JPEG 的 L\*，再比较色度和色相，这样色度比里不含曲线的影响。

推断：负片可以按 GR III 去追，两代数据一致，固件矩阵也相同。正片如果要追 GR IV，就要改黄、黄绿、青这几个扇区；红、品红、蓝、紫暂时只能留 GR III，等色卡。另外 Standard 本身两代就有差：相对 RAW，GR IV 在黄、青上比 GR III 多转 −2° 到 −8°。B 的光源是约 4000 K 室内灯，GR III 色卡是日光；色彩是否随光源变，未知。

### 5.4 负片灰轴（已验证）
方法：每 10 个 L\* 一带，拟合 JPEG ab = G·场景 ab + c，截距 c 就是场景中性在 JPEG 里的颜色。
- **B 负片减 Standard**：Δa\* 在 −0.64 到 +0.05，Δb\* 在 −1.11 到 −0.16，L\* 20–90 都在这个范围，不变号。
- **A 负片**：a0 在 −0.2 到 −0.8，b0 在 +0.3 到 +0.6，随亮度持平。
- **GR III 负片减 Standard**：除 L\* 90–100 的 Δb +0.95 外，都 ≤ 0.3。

也就是说，负片没有暗部偏青、高光偏暖的分色。它做的是去饱和（高光更多）加上色相转动，type 23 也用不上。富士 Classic Neg. 常被描述为暗部偏青绿、高光偏暖，这一点是背景知识，不是这次测的。

### 5.5 样本够不够
- **B**：黄、橙（45–105°）够；青（165–225°）够；绿（105–165°）勉强；红、肤色不够；蓝、紫、品红不够。场景色度中位只有 8–17。
- **A 正片**：只有天空蓝。
- **A 负片**：有红褐（约 9k 块）、橙黄（约 9k），蓝是低饱和的。

### 5.6 A 与 B 交叉核对
- **负片**：45–90° 上 A 的色度比 0.64–0.77，B 0.70–0.84，色相差 ≤ 3°；345° 两台都是 +24°。阶调差 0.3–2.5 码。
- **正片**：只在蓝上重叠，大体一致，但阶调 A 比 B 暗 1–7 码。
- **高对比黑白**：曲线差 ≤ 3 码，混合和颗粒都一致。
