# kv2-math-r1 验收报告

本任务交付独立整数数学模块，满足设计任务 B 的尺寸、工作区、栈和一致性要求。写入仅限 `firmware/kv2_modules/math` 与 `research/kv2_math`。未修改引擎，未生成 DAT，未连接设备、存储卡或网络，未启动子代理。

## 模块与接口

生产源码为 [kv_math.c](../../firmware/kv2_modules/math/kv_math.c)、[kv_math.h](../../firmware/kv2_modules/math/kv_math.h) 和 [kv_i64.c](../../firmware/kv2_modules/math/kv_i64.c)。入口为 `kv_apply_work(stock, base, request, out, stats, work)`。

计算顺序、Q12、对称舍入和启用位遵循冻结 r2。Amount=100 且各剂量为 0 时，输出原配方全部 552 B；Amount=0 且各剂量为 0 时，输出原厂 04 全部 552 B。两条路径均不重算 CRC 或修改未启用字段。

请求字段和剂量下标与冻结 `knobs.h` 一致。菜单调用方保持 `dose[9]=0`；核心保留参考中的 Tone 分支，供扩展剂量语料逐字节复跑。未增加菜单项目或设备调用。

工作区各部分依次为 base 552 B、result 552 B、stage union 1,104 B、request 52 B、stats 28 B，共 2,288 B。主机与 M32R 编译均通过尺寸静态断言。八字节对齐不增加总尺寸。模块没有可写静态区。

`out` 支持与 `stock` 或 `base` 完整及部分重叠。`work` 与 `stock`、`out`、`stats` 分离；`base=work->base`、`request=&work->request` 可用。无效请求返回 -1，Y 行和非正返回 -2；两种失败都不改输出及调用方统计。

## 尺寸、栈与符号

工具链为仓库已有 M32R GCC 13.4.0。构建使用 C11、`-Os -ffreestanding -fno-builtin -m32r -mmodel=medium -msdata=none -G0 -fstack-usage`，完整参数保存在 `firmware/kv2_modules/math/local/flags.json`。

| 项目 | 实测 | 上限 |
| --- | ---: | ---: |
| 目标代码 `.text`，含整数辅助函数 | 6,304 B | 与常量合计 |
| 常量 `.rodata` | 1,176 B | 与代码合计 |
| 代码加常量 | 7,480 B | 目标 7,500 B |
| 模块 `.data`、`.bss` | 均为 0 B | 无共享工作区 |
| 调用方 KvWork | 2,288 B | 2,288 B |
| 最大单函数栈帧 | 112 B，`blend` | 128 B |
| 最深静态调用链 | 248 B | 512 B |
| 全量目标执行观察到的栈深 | 248 B | 512 B |

最深链为 `kv_apply_work` 28 B + `apply_stages` 84 B + `blend` 112 B + `kv_round_div` 4 B + `__divdi3` 20 B。`.su` 全部为固定帧，调用图无递归、无间接调用。`__muldi3` 帧为 8 B，`__divdi3` 帧为 20 B，两者内部均无函数调用。

合并对象 `kv_math_all.o` 和独立链接 ELF 均无未解析符号。没有系统 libc 或浮点辅助函数。字节复制、清零、比较与重叠移动采用模块内有限循环；构建拒绝 VLA。生产源码没有堆分配和递归。

证据为 [尺寸与栈结果](size_stack_symbols.json)、[栈帧表](target_stack.tsv)、[调用图](target_calls.tsv)、[段表](target_sections.txt) 和 [符号表](target_symbols.txt)。目标二进制 SHA256 为 `4734af8ec07c92aa397935217ae9ac78ad524ec119a1ff4f47738dd922cd3d95`。

上述栈值覆盖独立数学入口和整数辅助函数。外层引擎、调用方参数区、服务、任务上下文和集成后的 LTO 结果由集成任务另行核对。本任务没有改动这些文件。

## 行为与目标执行

| 验收项 | 结果 |
| --- | --- |
| 冻结主套件 13,330 项 | 主机与 M32R 全部通过，比较完整 552 B、返回码和七项 stats |
| 扩展剂量域 2,504 例 | 主机与 M32R 全部通过同样比较 |
| 非法核心请求 492 例 | 返回 -1，输出及 stats 不变 |
| 原菜单非法请求 492 例 | 由冻结菜单代码连接新核心执行，输出不变 |
| A、B、A 回零 | 1,728 组复用工作区，与只改 B 完全一致 |
| 缓冲区重叠 | 主机 1,512 例，包含双输入同址、双向部分重叠和完整同址 |
| 默认两端 | 三个单元、24 个配方，共 48 例逐字节保留底子 |
| ASan 与 UBSan | 各覆盖同一组 20,000 例全剂量域和 20,000 例合法菜单请求 |
| 消毒器附加检查 | 2,304 例边界、空指针、工作区字段、重叠及 -2 返回检查 |
| 64 位辅助函数 | 主机、消毒器、目标各 100,121 组乘除比较 |

原套件的 13,330 计数包含 13,329 次完整计算和 1 个非法 Fade 的 Python 校验断言。本任务保留这条断言，并把同一请求送入冻结 C 核心，记录 -1、未变化的 552 B 输出和 stats，因此目标语料仍为同一组 13,330 项。

完整目标执行使用 `tools/native_harness` 的字节核对与解码，再由本目录 `target_runner.c` 执行实际 M32R 指令。全量运行不替换乘除函数，也不以主机数学函数代替目标代码。仓库原解释后端另外独立复核 101 例完整输出及 185 组乘除，包含大端参数、返回值和保存寄存器检查。解码缓存只写本任务 `local/`；没有读取 `tools/gxr_emulator`，没有使用目标运行库。

整数辅助函数通过两个 u32、16 位乘积和最多 64 轮长除法运算。乘法返回低 64 位，除法向零截断。辅助函数对零除数返回 0，对最小有符号值除以 -1 返回最小有符号值；合法数学请求不会使用这两个除法情形。

证据为 [主机结果](host_results.json)、[消毒器结果](sanitizer_results.json)、[目标结果](target_results.json)。这些结果是独立数学模块的目标指令执行证据，不包含相机、RTOS 或图像外观验收。

## 整数范围与除数

输入是已经验证的 552 B 展开条目，曲线节点严格递增且位于 0 到 4095。入口先拒绝越界 Amount、剂量和方法字段，再开始计算。

| 表达式组 | 范围及非零条件 |
| --- | --- |
| 曲线 warp | `gain` 为 4096 到 2^28，内部 `t`、`length-t` 均为正。分子小于 2^44，分母小于 2^36 且大于 0。 |
| Q16 插值 | 分子绝对值小于 2^36，节点差为 1 到 4095。插值结果在 0 到 `255*65536`。 |
| Amount 混合 | 两个权重绝对值之和不超过 200，Q16 分子绝对值小于 2^32，固定除数为 `100*65536`。其余混合除数为 100。 |
| 饱和度 | `wanted` 为 315 到 53248；`cg` 始终大于 0。颜色和矩阵幅值只在非零分支作除数，增益乘积小于 2^28。 |
| 行和调整 | cb、cr 绝对值分别不超过 240、290。Y 行和在使用前检查大于 0；中间 Y 系数绝对值不超过 5118，delta 保守上界 1484221，`delta*4096` 小于 2^33。alpha 的 32 位分子绝对值不超过 13623296，仅在 delta 非零时作除法。 |
| Fade、Filt、T1 与 Tone | 固定除数为 2、5、64、255 或 4096；T1 gain 至少为 4096。中间值小于上述 warp 上界。 |

所有组的 `kv_round_div` 分子加半除数仍小于 2^45，远小于有符号 64 位上限；其结果均在 32 位范围。CRC 使用 u32 运算。元数据偏移和长度缩为 u16、u8，数学系数仍为 32 位。
