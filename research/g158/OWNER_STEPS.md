# g158 现场步骤草案

先等新 SHA 的独立复审结论。本文件不授权安装或开始试拍；当前软件验收和 OPEN 见 [REPORT.md](REPORT.md)。机身仍为 v3.10 a04f1ed4，resident 不变。

换入 g158 后，g157 记忆会因 DAT 绑定不同被拒收，首次可见 B21/R3。先在 g158 成功手动保存一次目标配方，核对没有 Unsaved/ERR 或快门护栏，再正常关机重开检查 BOOT。test 开自动套用，release 仍关闭并显示策略原因 B02。

P/A/M/S 的已测入口是 M04、U00/U01/U02/U03，N 分别为8010/8020/8008/8800；Y、pending均为00。绿色 AUTO 在 g157 实机自动套用成功，能确认它落在旧许可范围内，M/U/N 原值尚未采到。SCENE、MY1–3、动态影像尚无现场内部值，继续 OPEN，不扩大许可。

## M/S 的 BOOT 后首次 ADJ

后续独立复审允许监督实测时，用已核对 SHA 的 g158 test 分别做 M、S 冷启动。g157 的正常旁证和本轮模型边界见 [SLOT31.md](SLOT31.md)。

1. 先在当前 g158 test 手动成功保存 Acros，核对没有 Unsaved/ERR 或护栏，正常关机。将拨盘放到目标 M 或 S，再单独开机。
2. 先做“ADJ 在先”的冷启动：不开其他菜单、不按快门，第一次按 ADJ，记录能否直接进入列表、Acros 是否选中、光标是否正确。当前模拟器边界对应这个顺序。保留包含包 SHA、拨盘档位和先后顺序的记录。
3. 正常关闭菜单，再手动选一次 Acros，分别检查 OK、ADJ 关闭后重开。把“BOOT 后第一次打开”和“手动套用后重开”分开记，后者不能代替前者。
4. 再关机，在同一个目标档独立冷启动，做“首拍在先”：不开任何菜单先拍一张，记录首张是否已为 Acros 黑白，再第一次按 ADJ，检查直接列表、选中项和光标。拍照会经过原厂曝光流程，不能用这次首次 ADJ 替代第2步。
5. 换成 LowSat，另做独立冷启动，重复上述两种顺序。M、S 各自冷启动，不在开机后转拨盘冒充另一档的 BOOT 验收。两种配方、两个档位、两种顺序共8次冷启动，逐次留记录。

release 的 BOOT 仍关闭，预期保持纯04并显示 B02；不能用 release 首张纯04判断 test 自动套用失效。若首次 ADJ 卡住、出现 ERR 或异常颜色，保留画面与操作顺序，停止该项，不反复按键消除现场。

## 可选：用 Status 采集尚未测过的档位

只在复审明确允许的后续监督测试中做。先选择一个已经验证的 P/A/S/M 档，在当前版本成功保存纯04，确认 >4 Std、没有 Unsaved/ERR/护栏，并关闭再开 ADJ 仍保持04。

1. 关机，将拨盘放到待采集的 SCENE、MY1、MY2、MY3、动态影像或绿色 AUTO，再正常开机。每个档位单独开机采样。
2. 首次 ADJ 若自动显示诊断，拍完整八行；若直接显示配方列表，进入末尾 Status 诊断页，拍完整八行。不要把随后改变拨盘位置后的 Status 当成新档位的实时读数，页面保存的是本次启动快照。
3. 抄录 M/U/N/Y，并同时保留 pending 的 P、F 失败位、activity、state、H、图像设定/WB 和读取结果 R。照片名称注明本次启动的物理档位和包 SHA。
4. Status 页本身只读，经过列表里的其他配方会预览并可能改写记忆。每轮结束后，回到已验证的 P/A/S/M 档重新成功保存纯04，再关机开始下一轮。

目标档若无法打开 ADJ 或没有 Status，记录“该档无可用页面”并停止这一项，不能把其他档位的页面冒充目标档读数。遇到 ERR、卡住、异常颜色或快门护栏，保留画面和操作顺序，不连续按键消除故障。

## 降级

必须先在当前 g158 保存纯04，再换旧 DAT。当前已是04时，先离开一行再回04以触发实际保存；核对没有 Unsaved/ERR/护栏，关闭再开 ADJ 保持04。之后不要为了看 Status 再经过其他配方，正常关机后由操作者更换已核对 SHA 的旧包。
