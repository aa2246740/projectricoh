# GXR Studio 界面 r1 · 报告

这一轮重做了 GXR Studio 的整套界面：设计规范，加上 17 个界面、2 页组件总览，共 37 张截图（每个界面 Mac 和外接屏两种尺寸，Windows 风格另补一张）。
风格：全深灰、不带色偏，照片周围默认中性深灰，可换 18% 灰或黑；只用一种蓝色做按钮和选中；没有绿色进度条和浏览器默认按钮。
新增两件事。一是"拍摄配方"：哪张用哪个机内配方拍的，在图库、胶片条、顶栏、信息面板里都能看到，可以按它筛选、分组，比较两张时并排显示。二是 Windows 也能用：字体和快捷键各有一套。
最想请机主先看的 3 张：`screenshots/05-编辑-配方-1728x1117.png`、`screenshots/02-图库-按拍摄配方分组-1728x1117.png`、`screenshots/14-比较两张照片-拍摄配方并排-1728x1117.png`。
配方效果和拍摄配方的数据都是示意，不是真实渲染，也不是这些照片的真实拍摄配方。没有改动 `studio/` 下的任何文件。

## 2. 风格要点

1. **深中性灰，照片是唯一的彩色。**
   - 灰阶全部 R=G=B；
   - 画面背景 `#2a2a2a`，比面板亮一档；
   - 可切 18% 灰（`#767676`）或黑。
2. **一种交互色**：蓝 `#2a64cc`。琥珀色只给"电脑预测 / 近似 / 未校准 / 推测"。
3. **布局像 Lightroom 和苹果"照片"的结合。**
   - 右侧 340px 工具面板，顶部 6 个图标标签：配方、调整、裁剪、边框、时间戳、信息；
   - 画面下方是视图工具栏和胶片条；
   - 顶栏放撤销、重做、复原、导出、存储卡状态。
4. **滑块是 LR / C1 式的一行。**
   - 中心零点；双击重置；点数值可以直接输入；拖动时有数值气泡；
   - 改过的数值变白，不加颜色。
5. **画面实时。** 中间是 canvas，拖动不转圈、不整块刷新。拆分和刷新的建议见 `HANDOFF.md` 第 2、3 节。
6. **两个平台同一套像素。** 不用原生下拉和日期选择器；快捷键、字体、平台叫法按平台变。

## 3. 机主截图里的问题怎么解决（摘要，详见 SELF_REVIEW 第 2 节）

| 问题 | 解决 |
| --- | --- |
| 浏览器默认灰按钮 | 四种按钮 × 五种状态；撤销、重做用图标按钮，配提示气泡 |
| 浅灰底不适合看颜色 | 固定深色，不跟随系统变浅；中性灰底 |
| 顶栏的"关闭"和绿色进度线 | 进度放进顶栏的存储卡状态（小圆环），点开看详情 |
| 零散的"成片""存储卡：可以推出" | 正常成片不写标签；存储卡状态挪进顶栏 |
| 边框卡片大小不一 | 统一 4:3 卡片，2 列，选中是蓝框 |
| 看不出用哪个配方拍的 | 拍摄配方：7 个位置 × 3 种来源 |
