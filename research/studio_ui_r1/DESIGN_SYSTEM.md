设计负责人写于 2026-11-02。令牌在 `tokens.css`，组件样式在 `screens/assets/ui.css`，所有组件和状态的样子见：

- `screenshots/00a-组件-控件-*.png`
- `screenshots/00b-组件-反馈与角标-*.png`

本文只讲规则和取值的理由。界面文案以 `research/studio_v2/COPY.md` 为准；本轮新出现、等待确认的词，见 `REPORT.md` 第 4 节。

## 0. 三条总原则

1. **照片是唯一的彩色。**
   - 界面全部是 R=G=B 的中性灰。
   - 只有一种交互色：蓝 `--accent`。
   - 琥珀色只给"电脑预测 / 近似 / 未校准 / 推测"这类小标签用。
   - 不出现绿色进度条、彩色分组或彩色图标。
2. **画面跟手。**
   - 中间是一块 canvas，由实时预览引擎（`research/studio_gpu_r1/`）驱动。
   - 拖滑块、拖裁剪框、转拉直刻度盘时，画面和数值都不加过渡，直接跟手（`--dur-instant: 0ms`）。
   - 动效只用在界面本身：面板开合、对话框进出。
3. **两个平台一致。**
   - 不依赖 macOS 专属外观：不用系统强调色，不用原生下拉和日期选择器，不用毛玻璃侧栏，不用红绿灯按钮。
   - Windows 和 macOS 用同一套像素。
   - 只有三处按平台变：快捷键写法、字体、少数平台叫法（推出/弹出、访达/文件资源管理器）。

## 2. 字体

```css
--font-ui: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB",
           "Microsoft YaHei UI", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif;
--font-mono: ui-monospace, "SF Mono", Menlo, Consolas, "Cascadia Mono", monospace;
```

- **macOS**：系统字体（SF）+ 苹方。**Windows**：Segoe UI + 微软雅黑（UI 版优先）。两个平台都是系统自带字体，不用授权字体。
- 数字一律用 `font-variant-numeric: tabular-nums`（`.num`）。拖滑块时数字宽度不跳。
- 时间戳的数码管字体 DSEG7 和打字机字体 Courier Prime 是照片内容，不是界面字体。两者都是 OFL 许可，沿用 `studio/src/gxr_studio/assets/fonts/`。

| 级别 | 字号 / 行高 | 用在 |
| --- | --- | --- |
| caption | 11 / 14 | 角标、小标签 |
| small | 12 / 16 | 次要文字、分组标题、提示气泡、分段控件 |
| body | 13 / 18 | 默认：控件标签、按钮、正文 |
| title | 15 / 20 | 面板标题、对话框标题、配方名 |
| headline | 20 / 26 | 空状态 |

字重只用 400 / 500 / 600。中文不用斜体，不用全大写。

## 3. 间距、尺寸、圆角、阴影、动效

- **间距**：4px 网格（2 / 4 / 8 / 12 / 16 / 20 / 24 / 32 / 48）。面板左右内边距 16px，控件行之间不再额外加距。
- **尺寸**：

  | 部位 | 尺寸 |
  | --- | --- |
  | 顶栏 | 48px |
  | 视图工具栏 | 40px |
  | 右侧工具标签 | 56px |
  | 面板底栏 | 56px |
  | 胶片条 | 92px（缩略图 96 × 64） |
  | 右侧面板宽 | 340px |
  | 左侧栏宽 | 232px |

- **可点元素最小 28 × 28 px**（`--hit-min`）：
  - 小按钮、分段控件每一段、下拉、输入框、滑块轨道、数值框，都是 28px 高；
  - 默认按钮 32px；
  - 视觉比 28px 小的东西，可点区域仍然是 28px：
    - 分段选中块看上去 24px，用 2px 透明边框补足；
    - 图库勾选圈看上去 20px，外层 28px；
    - 裁剪框边上的把手用伪元素把可拖区域扩到 28px。
- **圆角**：

  | 圆角 | 用在 |
  | --- | --- |
  | 3px | 角标 |
  | 5px | 小标签 |
  | 6px | 按钮、输入框 |
  | 8px | 卡片、提示条 |
  | 12px | 对话框、弹出面板 |
  | 999px | 胶囊 |

- **阴影**：只给浮起来的东西用，分为把手、弹出菜单、对话框、提示条四档。面板和卡片不加阴影，用 1px 白 6–10% 的线分隔。
- **动效**：

  | 令牌 | 时长 | 用在 |
  | --- | --- | --- |
  | `--dur-instant` | 0ms | 拖动中的画面、滑块数值 |
  | `--dur-press` | 60ms | 按下 |
  | `--dur-fast` | 100ms | 悬停、焦点 |
  | `--dur-base` | 160ms | 折叠、分段切换、开关 |
  | `--dur-slow` | 220ms | 对话框、弹出面板 |

  - 缓动用 `cubic-bezier(.2,0,0,1)`。
  - 系统打开"减少动态效果"时，除 0ms 以外全部归零。

## 4. 组件

每个组件都有：默认、悬停、按下、禁用、键盘聚焦。聚焦统一是 2px `--focus-ring` 外框，偏移 2px，只在 `:focus-visible` 时出现。

### 4.1 按钮（`.btn`）

| 种类 | 类名 | 样子 | 用在 |
| --- | --- | --- | --- |
| 主 | `.btn.primary` | 蓝底白字 | 每个界面最多一个：导出、完成、存储为我的配方、导入照片 |
| 次 | `.btn` | 灰底 + 1px 细线 | 取消、重置、设为默认、自动、向左旋转 |
| 危险 | `.btn.danger` | 红底白字 | 只出现在确认对话框里：删除 |
| 图标 | `.btn.icon` | 透明底，28 × 28 | 撤销、重做、对比、上一张/下一张、关闭；**必须有提示气泡**，写名称和快捷键 |
| 幽灵 | `.btn.ghost` | 透明底，有字 | 顶栏的"照片""复原"，提示条里的动作 |

- **悬停**：底色亮一档，描边变强。
- **按下**：底色再亮一档，有字按钮缩到 98%（图标按钮不缩，保证 28px 可点区域）。
- **禁用**：字变 `--text-disabled`，底变平；用 `aria-disabled`，仍可以显示提示气泡，例如"暂不支持写入存储卡"。
- **打开状态**（例如正在看原图）：图标按钮用 `aria-pressed="true"`，显示蓝 16% 底和蓝色图标。

### 4.2 滑块（`.sl`，中心零点）

```
标签 76px │━━━━━━━━━━┃━━━●━━━━━━│ +12   ← 一行 32px
```

- **中心零点**：中间一根 8px 的刻线；填充从零点画到滑块（蓝色细线），值为 0 时没有填充。
- **改动标识**：值 ≠ 0 时，标签和数值从 `--text-2` 变成 `--text-1`，不另加颜色。
- **双击复位**：双击滑块或标签，回到 0（无中心的滑块回到默认值）。提示气泡写"双击重置"（COPY 3.12）。
- **直接输入**：单击数值进入输入状态（蓝框）。回车或离开时提交；Esc 取消；↑/↓ 每次一档，⇧ 加 ↑/↓ 每次十档；超出范围的值自动夹到范围内。
- **拖动时显示数值**：滑块上方出现白底数值气泡，滑块放大到 1.33 倍并带一圈光晕；松手后气泡消失。
- **键盘**：轨道获得焦点后，←/→ 一档，⇧ 加 ←/→ 十档，Home 回 0。
- **无中心滑块**：强度（0–100%）、导出品质（60–100）不画零点，填充从左端开始。
- **禁用**：标签、数值、滑块都变灰。可以挂小标签，例如"仅电脑"。
- 可点区域：轨道 28px 高，数值框 28px 高。

### 4.3 分段控件（`.seg`）

- 底槽 `--surface-control`，选中块 `--surface-selected` 并带一点阴影。
- 每段 28px 高，等宽；放在表单行里时撑满（`.seg.block`）。
- 也可以多选（例如边框的"显示：标志 / 参数 / 日期"），多选时每段各自是一个开关按钮（`aria-pressed`）。

### 4.4 开关（`.switch`）

- 32 × 18 的轨道，整个 28px 高的行都可以点。打开是蓝色。
- 禁用时轨道变暗、圆点变灰。

### 4.5 折叠面板标题（`.section-head`）

- 36px 高：左边箭头和标题；右边放这一组的重置（↺）或开关（例如"时间戳"的总开关）。
- 收起时箭头转 −90°，动效 160ms。
- 展开/收起状态按面板记住，存在本机浏览器里，不写进照片。

### 4.6 工具栏

- **顶栏**（48px）：
  - 图库页：左边是名称 + "照片 / 配方 / 相机"；右边是存储卡状态、导入、导出、快捷键、设置。
  - 编辑页：左边换成"‹ 照片"、撤销、重做、复原，然后是文件名、拍摄时间、文件类型、拍摄配方。
- **视图工具栏**（40px，画面正下方），从左到右：
  - 原图、左右对比；
  - 背景色点；
  - 小标签槽（电脑预测 / 近似）；
  - 中间是上一张 · 计数 · 下一张；
  - 右边是"适合 / 100%"。

### 4.7 胶片条缩略图（`.fthumb`，96 × 64）

| 状态 | 样子 |
| --- | --- |
| 当前 | 2px 白框，内侧再加 1px 黑线，保证在白色照片上也看得见 |
| 选中（多选） | 2px 蓝框 |
| 其他 | 透明度 82%，悬停 100% |
| 拍摄配方 | 左下角小角标：只写编号（`05`）；Looks 写名字；推断的加 `≈` 和虚线框；未知不显示 |
| HDR | 左下角白底黑字 `HDR` |
| 已调整 | 右上角黑底小图标（调整图标） |

文件类型不在胶片条上显示；当前照片的文件类型写在顶栏。

### 4.8 图库缩略图（`.cell`）

- 3:2 格子，照片按 contain 放进去，竖片两边留深灰。
- 左下角依次放：拍摄配方（完整名称）、"只有 JPG"、"HDR"。右下角放已调整图标。左上角是选择圈。
- **RAW+JPEG 不打角标**：这是正常状态，打了就是满屏噪音。只给例外状态打角标："只有 JPG"，以及只有 RAW 时的"电脑预测"。
- 角标都能在"视图选项"里关掉：拍摄配方 / 文件类型 / HDR / 已调整。

### 4.9 拍摄配方的三种来源（新）

拍摄配方指机内拍摄时用的配方，和电脑上后来套的配方或 LUT 是**两个字段**，任何地方都不合并显示。

| 来源 | 缩略图角标 | 单张查看（顶栏） | 信息面板 |
| --- | --- | --- | --- |
| 相机记录 | 实底 + 相机图标 + 名称：`📷 05 富士 CC` | 相机图标 + 名称 + "相机记录" | 名称（15px）+ 小标签"相机记录"；下面是机内微调 |
| 推断 | 同样的实底，加白色虚线框 + `≈`：`≈ 02 GR 负片` | 虚线框 + `≈ 名称` + "推断 83%" | 小标签"推断 · 可信度 83%"；下面列"其他候选" |
| 未知 | 不显示 | 相机图标 + "拍摄配方未知" | 小标签"未知" |

- **推断的显示门槛**：可信度 < 60% 时，缩略图和胶片条按未知处理，不显示；信息面板仍然列出候选。门槛在"视图选项"里写明。
- 配方面板顶部固定一行"拍摄配方"。内置配方或 Looks 里，和拍摄配方相同的那一格，右上角有相机小图标。
- **颜色区分**：拍摄配方用中性色加相机图标；电脑上的效果用琥珀色的"电脑预测"。所以两者一眼能分开。

### 4.10 对话框（`.dialog`）

- 宽 520px（快捷键表 1080px），圆角 12px，后面是 56% 黑的遮罩。
- 标题 15px 半粗；右上角有关闭按钮。底部按钮靠右，顺序是 [取消] [主动作]。
- 危险确认用苹果写法：标题"删除 3 张照片？"，按钮 [取消] [删除（危险）]，不另写说明句。
- Esc 关闭；回车触发主按钮；焦点锁在对话框内。

### 4.11 提示条（`.toast`）

- 浮在画面下方的中间，圆角 8px，停留 3.2 秒，鼠标悬停时不消失。
- 三种：
  - 进度：小圆环 + "正在导出 3/12" + [取消]；
  - 结果：对勾 + "已导出 12 张" + [在访达中显示]；
  - 出错：红色左边线 + "无法……。请……。" + 关闭。
- 只在看不到结果的操作后出现（COPY 3.10 总规则）。

### 4.12 进度

- **不再用整条页面宽的进度线。** 进度放在发起它的那个东西上：
  - 导入：顶栏的存储卡状态变成小圆环 + "正在导入 12/40"。点开是弹出面板，里面有 4px 圆角进度条、当前文件名、刚导入的几张缩略图和 [取消]。
  - 导出：提示条里的小圆环。
  - 生成配方（LUT 页）：卡片里的 4px 进度条 + 百分比。
- 不确定时长的等待不用转圈，用文字"正在读取…"。实时预览本身不应该出现等待。

### 4.13 小标签、角标、键帽、提示气泡

- **小标签**（`.tag`，20px 高）：
  - 琥珀：电脑预测、近似、未校准、推测；
  - 中性：仅电脑、原图、RAW+JPEG；
  - 拍摄配方专用："相机记录"实底、"推断"虚线。
- **键帽**（`.kbd`）：
  - Mac 用 ⌘ ⇧ ⌥ ↩ 符号，挨在一起写；
  - Windows 用 Ctrl / Shift / Alt / Enter，用"+"连接。
- **提示气泡**：浅底深字，写"名称 + 快捷键"，例如"撤销 ⌘Z"或"撤销 Ctrl+Z"。不写教学句。

## 6. 跨平台细则

| 项 | macOS | Windows |
