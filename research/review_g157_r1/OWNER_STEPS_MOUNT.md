# MOUNT test 现场步骤

当前暂停上卡。本轮复审发现 P1：一次写回执失败就能在显式套用后留下半套单元颜色，回到取景且没有 DIRTY/GUARD。下列流程只在修复并独立复审新 SHA 后启用，见 [复审结论](REVIEW.md)。

先拍开机后的首张照片，再打开 ADJ。首次诊断最有价值，不要先手动套一次配方再判断 BOOT 是否成功。

本流程原计划用于 2026-11-05 的有监督 MOUNT 试拍。使用现有 v3.10 机身，机身身份为 `a04f1ed4`，不刷写机身。下面是本轮被阻止上卡的 test DAT 身份，仅供识别，不能作为放行值。release 不替代本流程。

```text
3478b9954c122142a0711ff07cc7251a50abb442f7069cc2c558d1ca61f882a3
```

相机已经装好 MOUNT，电量充足，照片采用 RAW+JPEG。使用固定、有彩色物体的场景，保持 M 档及曝光设置。开始前由监督者确认原厂 Image Settings 为 Standard、WB 补偿为 0,0。不能确认时，先收集下文的 B20 诊断，不把它当作自动恢复失败。

表内的 P 是用手机拍的证据，J 是用 GXR 拍的 RAW+JPEG。一个编号只做一个动作。涉及移动游标的步骤，每按一次键拍一张手机照片；没有到指定条目时只重复该步骤，不长按。

## 装入指定 DAT

| 步骤 | 只做这个动作 | 要拍什么，以及画面代表什么 |
| --- | --- | --- |
| 1 | 按电源关机。 | P01，拍黑屏。若仍有写卡指示，先停在这里。 |
| 2 | 等写卡指示灯熄灭。 | P02，拍已熄灭的指示灯。 |
| 3 | 取出 SD 卡。 | P03，拍取出的卡。 |
| 4 | 将卡接到电脑。 | P04，拍电脑中该卡的根目录。 |
| 5 | 把卡上原来的 `GXRCE.DAT` 备份到电脑。 | P05，拍备份文件和文件名。保留它供 DAT 回退使用。 |
| 6 | 用后续独立复审明确放行的替代 test 文件替换卡根目录的 `GXRCE.DAT`。 | P06，拍根目录中的文件名和大小。大小不能代替 SHA 核对；当前被阻止的文件不能用于这一步。 |
| 7 | 计算卡上 `GXRCE.DAT` 的 SHA-256。 | P07，拍完整校验输出。若等于上面的旧 SHA，停止；只有后续复审明确放行的新 SHA 才能继续。 |
| 8 | 正常弹出 SD 卡。 | P08，拍电脑已经弹出的状态。 |
| 9 | 把卡插回相机。 | P09，拍已插回的卡和卡槽盖。 |
| 10 | 把拨盘放在 M。 | P10，拍拨盘位置。接下来直到 J03 拍完都不转拨盘。 |

## 第一次开机，建立 g157 的记忆

第一次由 g156 换成 g157，旧记录的 DAT 绑定不同，不能期待它自动恢复旧配方。B21 或 `R00` 本身不表示安装失败；若模式或 activity 同时不合格，会优先显示 B11 或 B10。

| 步骤 | 只做这个动作 | 要拍什么，以及画面代表什么 |
| --- | --- | --- |
| 11 | 按电源开机。 | P11，拍刚进入取景的画面。先不打开 ADJ。 |
| 12 | 按一次快门拍摄固定场景。 | J01，保留 RAW+JPEG。这是第一次开机、打开 ADJ 以前的颜色证据。快门不响应时拍 P12 手机照片并停止。 |
| 13 | 按一次 ADJ。 | P13，拍完整屏幕。出现 `G157B..R..` 是 g157 诊断；出现配方名称是 g157 列表；只有原厂项目则转到“整张列表消失”。 |
| 14 | 若当前是诊断页，按一次 OK。 | P14，拍返回后的配方列表。正常仍是八个可见行，可以滚动到其他配方。诊断页不能返回时停止。若第 13 步已经是列表，跳过此步。 |
| 15 | 若游标不在 `3 HC BW`，按一次上或下，向它移动一行。 | P15-序号，拍游标、`>` 或 `~` 及条目名称。重复本步直到到达 `3 HC BW`。移动到配方通常已经试套并记忆它。 |
| 16 | 按一次 OK。 | P16，拍当前画面。若出现配方卡片，继续第 17 步；若已经回取景，跳过第 17 步。若只是 `~3` 的记忆预选，本次 OK 才会显式套用。 |
| 17 | 若仍在配方卡片，按一次 OK。 | P17，拍回到取景后的画面。若仍不能退出，停止，不连续按键。 |
| 18 | 按一次快门拍摄同一场景。 | J02，保留 RAW+JPEG。应是 HC BW 黑白。若仍明显有彩色，停止。 |
| 19 | 按一次 ADJ。 | P19，拍 `3 HC BW` 的 active 标记。`>M01 Unsaved`、`>M02 Unsaved` 或 `>M03 Unsaved` 都要保留照片并停止本轮。 |
| 20 | 按一次 ADJ。 | P20，拍回到取景的画面。 |

最小主线不修改 HC BW 参数。若需要验证非默认值，另开一轮，只改一个参数，并拍下修改后的卡片。本轮关机前与下次开机的对照必须使用同一条记录，不能中途换 Look。

## 第二次开机，区分记忆与实际颜色

| 步骤 | 只做这个动作 | 要拍什么，以及画面代表什么 |
| --- | --- | --- |
| 21 | 按电源关机。 | P21，拍关机后的黑屏。 |
| 22 | 等写卡指示灯熄灭。 | P22，拍已熄灭的指示灯。 |
| 23 | 按电源开机。 | P23，拍首次取景画面。保持 M，先不碰 ADJ。 |
| 24 | 按一次快门拍摄同一场景。 | J03，保留 RAW+JPEG。它与 J02 的对照回答 BOOT 是否真的恢复了黑白。快门被拦时拍 P24 并停止，不反复尝试。 |
| 25 | 按一次 ADJ。 | P25，拍首次出现的完整八行。若是诊断页，必须先拍下再按下一步。 |
| 26 | 若当前是诊断页，按一次 OK。 | P26，拍返回后的列表。若第 25 步已经是列表，跳过此步。 |

按下表解释 P25、P26 和 J03。

| 看见的组合 | 代表什么 | 接下来做什么 |
| --- | --- | --- |
| J03 黑白，列表 `>3 HC BW`，记忆也为 03。 | 本次开机的自动套用与照片表现相符。 | 保留三项证据，进入 Look 抽测。它还不是 NAND 或所有机型验收。 |
| B11，记忆 `R03`，active 为 `A04`，J03 彩色。 | 实际模式或原厂选择组合未获 BOOT 许可。g157 没有扩大这个门，固定 M 仍可能这样。 | 拍整页，尤其 M/U/Y/P 行。收完证据后可按下面的“手动恢复”。 |
| B10，记忆 `R03`，J03 彩色。 | BOOT 入口的 activity 不符合当前合同。 | 拍整页，尤其 A/H 行。不要把进入 ADJ 后的 activity 当作启动值。 |
| B01，模式和 activity 显示问号。 | 本次 DAT 没有观察到合格的 BOOT 派发；这些启动原值未知。 | 拍整页。问号不是坏内存，也不能据此推断 M 的内部模式值。 |
| B20，记忆 `R03`，active 为 `A--`。 | 已读回记忆，但 Vivid、其他原厂图像设定或非中性 WB 阻止自动套用。 | 拍整页和原厂 Image Settings、WB 页面。先保留原状态，不先居中再拍证据。 |
| B21 或 `R00`。 | BOOT 当时没有读到可用的 g157 记忆。第一次换代常见；若 H01 稍后才读回，第一行也可能已经变成 `R03`。 | 拍整页及 R 子码。第 19 步显示成功、下次仍为 `R00` 时，记忆恢复未通过；B21 配合 `R03` 要另查启动就绪时序。 |
| B22 或 B23。 | 原厂完整颜色基线不符，或原厂锁忙；引擎干净跳过套用。 | 拍整页，停止本轮并交给监督者。 |
| B30、B31、ERR、快门被拦，或卡住。 | 对象/epoch 变化，或颜色事务/补偿出现故障。B31 有时已回到完整 04，仍要保留故障证据。 | 停止。不要靠反复快门、换配方或开关机试着消除它。 |

## 手动恢复与 Look 抽测

只有列表正常、没有 ERR，也没有 B30/B31 或快门保护时，才走这段。B10/B11/B01 的干净跳过可以在收证后手动恢复；它不会修复下一次 BOOT。

| 步骤 | 只做这个动作 | 要拍什么，以及画面代表什么 |
| --- | --- | --- |
| 27 | 若 J03 是彩色且游标正停在记忆的 `~3 HC BW`，按一次 OK。 | P27，拍配方卡片。它表示一次显式套用，不能算成 BOOT 成功。若已经 `>3`，跳过本步。 |
| 28 | 若第 27 步仍在卡片，按一次 OK。 | P28，拍回取景后的画面。 |
| 29 | 若做过手动恢复，按一次快门。 | J04，应为黑白。仍有彩色或快门不响应就停止。 |
| 30 | 按一次 ADJ。 | P30，拍当前列表。 |
| 31 | 按一次上或下，向 `HNCS LowSat` 移动一行。 | P31-序号，拍当页。未到目标则重复本步。停在它上面时应保留名称及 active 标记，不应变成 Unsaved。 |
| 32 | 按一次 OK。 | P32，拍 LowSat 卡片或取景画面。 |
| 33 | 若仍在 LowSat 卡片，按一次 OK。 | P33，拍取景画面。 |
| 34 | 按一次快门。 | J05，保留 LowSat RAW+JPEG。 |
| 35 | 按一次 ADJ。 | P35，拍重新打开的列表和 LowSat 标记。 |
| 36 | 按一次上或下，向 `Acros` 移动一行。 | P36-序号，拍当页。未到目标则重复本步。Acros 是最后一个 Look，后面是三个用户项和 Status；出现它证明能到达恢复后的列表末端。 |
| 37 | 按一次 OK。 | P37，拍 Acros 卡片或取景画面，不应出现 Unsaved。 |
| 38 | 若仍在 Acros 卡片，按一次 OK。 | P38，拍取景画面。 |
| 39 | 按一次快门。 | J06，保留官方 Acros RAW+JPEG。 |
| 40 | 按一次 ADJ。 | P40，拍重新打开的 Acros 标记。到此可停止抽测。 |

`>` 是当前套用标记，`~` 是记忆标记，游标高亮是第三件事。Look 名称前的 `*` 表示参数经过调整，不等于 Unsaved。不能凭游标位置或 Standard 标签断言配方已生效。

再次看诊断时，一次一行地移到列表末尾的 `Bxx Status`，每按一次键拍一张；停在 Status 后按一次 OK，拍整页；再按一次 OK，拍返回列表。移动到 Status 之前经过配方会试套颜色，因此不在 J03 之前这样做。

## 诊断码查表

| B 码 | 含义 |
| --- | --- |
| B00 | 没有锁存跳过原因。自动成功通常直接进入正常列表，不会自动弹 B00 页。 |
| B01 | DAT 没看到合格的 BOOT 派发。 |
| B02 | 当前包关闭 BOOT 策略。release 正常会这样；本次指定 test 不应如此。 |
| B10 | 启动 activity 不合格。 |
| B11 | 内部模式或原厂选择组合未确认。 |
| B12 | MY 激活。 |
| B13 | 原厂模式切换尚未结束。 |
| B14 | 设置来源、指针、长度或 BOOT 调用参数不可用。 |
| B15 | 启动 state 不在允许窗口。 |
| B20 | 原厂图像设定或 WB 阻止自动套用。 |
| B21 | 记忆缺失、来自另一 DAT，或记录不合法。 |
| B22 | 完整原厂九行或 T 与所需基线不符。 |
| B23 | 原厂参数锁忙。 |
| B30 | epoch、对象、单元或事务身份发生变化。 |
| B31 | 颜色事务或补偿失败。一次补偿成功也会保留这个首次故障码。 |

第一行 `G157B11R03` 的 `R03` 是记忆的基础配方 03。`R00` 是没有可用记忆，`R80` 至 `R82` 是三个用户项，其他高值可能是全局 Look 编码，不能当作列表中的第几行。第二行的 `A03`、`A04` 是实际确认的配方，`A--` 是尚未确认，不能把它写成纯 04。

V/T/R 行末尾的单字符 R 是另一种值，表示锁存时的记忆读取结果。R1 有效，R2 没记录，R3 属于别的 DAT 或版本，R4 单元不符，R5 结构/CRC/索引不合法，R6 参数不合法，R7 设置源暂不可用。第一行的记忆编码可能在 H01 读回后更新，行末的 R 仍保留 BOOT 原因。不要把两者混在一起。B01 页中的问号表示未采到启动原值。

F 行是所有已检查失败条件的集合，不只有 B 码所指的一个原因。M/U 是内部模式与子模式，Y 是 MY，P 是 pending，A 是启动 activity，H 是已观察入口的位集。H 中 H50 的一位来自现有 pending 合同推断。V 是启动 state，T 是事务阶段，N 是原厂选择，L 是来源。L03 是卡，L01/L02 是内部副本。S 行保留设置对象与长度供本地分析，不要手抄地址到公开 issue。I 行是原厂图像选择与 WB 的编码，`01` 为 Standard，`09` 为 Vivid，WB 两轴 `09/09` 为中性。Q 是 resident 状态。D/G 是入口快照中的 DIRTY/GUARD，不代表后来所有操作都成功。

Unsaved 的 M01 是忙锁，可在下一次用户操作边界重试；M02 是外来尾部，不能覆盖；M03 是结构或参数拒绝。都先拍照，不用反复按 OK 试着消掉它。

## 整张列表消失与回退

若 ADJ 只剩原厂项目、没有 g157 标题，也没有任何配方名称，先拍完整页面。再拍机身版本页，记录它发生在第一次开机还是第二次开机，以及两次之间有没有动卡。版本页仍可能显示 1.51，单凭它不能确认已经刷入修改后的 v3.10。当前 v3.10 resident 未改，DAT 未加载、DAT 被退役或首次菜单发布失败时，g157 的诊断也可能完全看不到。没有 B 码不能排除故障，也不能说明文件坏了。

停止继续拍摄，由监督者先保留卡上 DAT 的 SHA、目录截图和已有 P/J 文件。不要先格式化、重复制或刷机，否则会丢掉区分现场原因的条件。

正常降级到 g156 前，先在仍能工作的 g157 列表中保存纯 04。否则高索引 g157 Look 的记忆可能让 g156 一直显示 Unsaved，下一次换回 g157 还可能重新恢复旧的 Look。

| 步骤 | 只做这个动作 | 要拍什么，以及画面代表什么 |
| --- | --- | --- |
| R1 | 在 g157 列表里按一次上或下，向 `4 Std` 移动一行。 | PR1-序号，拍当页。未到目标则重复本步。 |
| R2 | 按一次 OK。 | PR2，拍纯 04 卡片或取景画面。 |
| R3 | 若仍在卡片，按一次 OK。 | PR3，拍取景画面。 |
| R4 | 按一次 ADJ。 | PR4，拍 `>4 Std`，确认没有 Unsaved。 |
| R5 | 按一次 ADJ。 | PR5，拍退出菜单后的画面。 |
| R6 | 按电源关机。 | PR6，拍关机后的黑屏。 |
| R7 | 等写卡指示灯熄灭。 | PR7，拍熄灭的指示灯。 |
| R8 | 取出 SD 卡。 | PR8，拍取出的卡。 |
| R9 | 将卡接到电脑。 | PR9，拍卡根目录。 |
| R10 | 用第 5 步的备份替换卡根目录的 DAT。 | PR10，拍替换后的文件。 |
| R11 | 核对回退 DAT 的完整 SHA。 | PR11，拍完整输出，并与备份 SHA 比较。 |
| R12 | 正常弹出 SD 卡。 | PR12，拍已弹出状态。 |
| R13 | 把卡插回相机。 | PR13，拍卡槽盖。下一轮由监督者单独决定。 |
