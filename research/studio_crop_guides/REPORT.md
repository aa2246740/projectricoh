# studio-crop-guides-r1：裁切的社交媒体比例与构图辅助线

范围：`studio/`（前端 `web/assets/`、后端 `crop.py` 三行、测试、README）和本目录。没有碰相机、真实的卡、真实的图库和应用数据目录，没有联网，没有 git 写操作，没有启动子代理。

## 一、做了什么

1. **比例分两组**
   - 常用：原比例、自由、1:1、3:2、4:3、16:9、XPan 65:24。
   - 社交媒体与屏幕：小红书 3:4、Instagram 4:5、Instagram 1:1、Instagram 横图 1.91:1、公众号封面 2.35:1、微博 16:9、抖音 / 视频号 9:16、电脑壁纸 16:10。
   - 原比例、自由、1:1 不分横竖；其余比例有「横 / 竖」两个按钮。
2. **构图辅助线**（叠在裁切框里，半透明白线）：关、三分线、黄金比例（0.382 / 0.618 两个方向各两线）、黄金螺旋、对角线、中心十字、网格 4×4（每边 4 格，3 条内线）。
   - 快捷键：**G** 循环切换辅助线（一圈回到"关"之前的那个，包括"关"）；**O** 切换螺旋方向（1/4 → 4/4 循环）。只在裁切标签里生效，和 C / R / A / E 不冲突；已加到「?」快捷键表。
3. **拖动与变淡**：拖动框、拉动框大小滑块、拉直滑块时辅助线完整显示；松手后变成 35% 透明度。面板里「拖动时看清，松手后变淡」可以关掉（关掉后松手仍然清楚）。
4. **默认行为**：没有裁切的照片打开裁切时是「原比例 + 三分线」。已经裁过的照片保留它保存的比例。
5. **去掉自动推荐 XPan**：16:9 照片的建议提示和「裁成 XPan」按钮都已删除（`web/assets/crop.js`）。之前 `onboarding.js` 的说明文字只写"可以裁成 XPan 全景条或其他比例"，没有自动推荐，未改。
6. **后端**：`crop.py` 的 `PRESETS` 新增 `16:10`、`1.91:1`、`2.35:1` 三个比例。横竖沿用已有的 `flip` 参数（只在 `rect` 为空时生效），接口没有其他变化。

## 二、设计选择（交复审时可以改）

- **社交比例不另起 id。** 小红书 3:4 就是比例 `4:3` 的竖向；抖音 / 视频号 9:16 就是 `16:9` 的竖向。保存到 sidecar 的仍然只有比例和框，不记平台名。
- **横竖状态由框的实际形状推出**，不另存。切横竖 = 重新算一个居中的最大框，`flip` 取值为"想要的方向 ≠ 照片本身的方向"。拉直、缩放沿用当前方向。
- **按钮亮起的规则**：比例 id 相同，并且方向也相同才亮。所以「常用 4:3」和「小红书 3:4」不会同时亮。「常用 1:1」和「Instagram 1:1」是同一个比例，会同时亮，这是有意的。
- **黄金螺旋的"四个方向"是翻转，不是旋转。** 螺旋中心放在四个黄金分割交点之一（左右翻、上下翻组合），O 键依次切换。曲线是每转 90° 半径乘 φ 的对数螺旋，即黄金螺旋的常用画法，不是 Fibonacci 方块的圆弧。
- **辅助线的坐标系**：SVG 的 viewBox 宽高比取框的真实宽高比，线条用 `vector-effect: non-scaling-stroke`，所以线宽固定，螺旋不变形。
- **辅助线偏好**（开哪种线、螺旋方向、是否变淡）存在这台电脑的浏览器 `localStorage` 里，键名 `gxr-studio.crop-guides`。**不进照片的编辑记录**，换浏览器不会同步。这一点请复审时确认。

## 三、比例数值与依据（需要人工核对）

**本次没有联网，以下数值是凭记忆整理的，没有对照各平台的当前官方规范。** 数值本身是常见的标准比例；下表只标明我的把握程度。

| 按钮 | 比例 | 默认方向 | 依据 | 把握 |
|---|---|---|---|---|
| 小红书 3:4 | 3:4 | 竖 | 小红书常用竖图比例 | 中。官方规范未核对 |
| Instagram 4:5 | 4:5 | 竖 | 常见竖图规格（如 1080×1350） | 较高 |
| Instagram 1:1 | 1:1 | — | 常见方图规格（1080×1080） | 较高 |
| Instagram 横图 1.91:1 | 1.91:1 | 横 | 常见横图 / 链接预览比例（1080×566） | 较高 |
| 公众号封面 2.35:1 | 2.35:1 | 横 | 常见封面尺寸（900×383） | 较高 |
| 微博 16:9 | 16:9 | 横 | 常用横图比例，微博**没有**强制规定 | 低。这是习惯比例，未核实官方规范 |
| 抖音 / 视频号 / Story 9:16 | 9:16 | 竖 | 常见竖屏比例（1080×1920） | 较高 |
| 电脑壁纸 16:10 | 16:10 | 横 | 常见显示器比例；不是社交平台，按要求放在同一组 | 较高 |

**请复审的人对照各平台当前的官方说明，尤其是小红书和微博两行。** 如果要改数值，只改 `web/assets/crop.js` 的 `PRESET_GROUPS`，如果比例 id 有变，还要同步 `crop.py` 的 `PRESETS`。
