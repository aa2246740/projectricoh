# 没有可上卡的 MOUNT 改进

本轮 g157 MOUNT 新增候选清单为空。18 条 g156 MOUNT 记录保持，新增净字节为 0，test 余量仍为 156 B，release 仍为 2,016 B。所有成绩均为电脑预测，没有构建 DAT、访问相机或 SD 卡、联网、安装依赖、commit 或 push。

21 个有界拟合实例和 1 个原生04保持实例覆盖 20 个配方；其中 Portra 400、Metropolis 另从上一轮 flags=1 失败记录各重试一次。全部非原生实例均用冻结的参考 exact 路径重跑完整声明起点，并穷举本轮局部域的全部可行整数记录。全部参考结果与迭代记录的有效参数相同。

## 局部分支和门槛

本轮只测试 node 16 的局部改动，正负各最多 2 码。其余节点、横轴、矩阵、扇区、flags 和色彩选择器均固定。flags=1 继续使用一条共享曲线；flags=7 保留三条独立曲线。04 不拟合。此结果不排除其它节点或更大参数搜索存在改进。

分支按通道、符号、条件输入亮度和色相拟合 Y/Cb/Cr 的加性残差斜率。只有已采样输入范围与邻近色相支持中的查询才使用校正，其余查询继续用原模型并标记外推。条件输入不是 RAW_WB，也没有把自由核峰位、宽度或反推幅度写回硬件节点。肤色、蓝块与灰阶没有合并成统一 RGB 倍率或固定色度矩阵。

拟合适配器使用 recipe-redo 已冻结、带授权哈希的 fit_fast 第二轮 guarded_normal 交付。局部 L0/L1 坐标实际使用原有 exact TRF/SVD 回退，没有使用并行开发的第三轮求解器。参考复核直接使用冻结的 ceiling_model.Problem；最终评分独立解码 552 B 记录。连续代理的半码舍入不能参与整数选型，灰度目标也不能偷偷切换 Standard 的物理色彩链。首次失败和恢复日志保留在 local 中。

整数记录只按训练目标与固定色相、渐变夹具选型，照片不参与挑参数。0.1 个百分点门按逐照片相似度中位数检查；None 保持 None，逐照片绝对中位与 P95 均不得回退。ISO200 每个原场景及七张自然 RAW 整组的中位与 P95 门全部保留。Agfa LeBox 和千禧回声 A 始终对原通过记录检查，没有拿上一轮失败记录重设门槛。

## 两处符号缺口没有关闭

肤色 R+ Cb、蓝块 B+ Cr 在包含同色观测的校准点上都转为实测方向，81 个提取分支也保持正向；去掉对应颜色后，两处都回到旧的错误方向。2/2 的训练点修正、0/2 的同色留出修正说明，这些观测还不足以支持未见过的肤色或蓝色响应。蓝块 B− 的训练符号在背景敏感性下还会翻转，并继续依赖 RAW 基线模型。

三个 ROI、插值与首尾 A、三种背景、均值与分块均值及 RAW 直方图共 81 个并行提取分支保留；首尾 A 漂移另有两个方向分支。模型误差预算取历史探针原模型、probe2 与新分支残差的逐通道逐分量最大值，另保留原 128 个量化分支，没有换成较窄的 ROI 包络。该预算是敏感性检查，不是置信区间或未知中间漂移的上界。完整组合没有被宣称为全颜色硬件验收。

## 证据与复跑

[原门槛与逐条变化](local/holdout_changes.csv)、[候选与记录哈希](local/g157_mount_candidates.json)、[行池容量计数](local/capacity.json)、[真实None目标检查](local/native04_none_gate.json)和[最终核验](local/final_audit.json)均保存在被 Git 忽略的 local 中。799个冻结文件重验通过，21个拟合实例的465个可行整数点均经迭代与参考路径分别计算，117次参考exact起点求解均有收据。198个真实None照片目标通过绝对误差门。冻结输入同时绑定两条 decisions.tsv 原文、probe3交接、probe2测量和历史误差预算。自然场景使用冻结RAW目标表并核对npz哈希，没有重新提取或拍摄自然照片。

旧后端曾自动刷新一份共享适配器元数据回执，已按最初冻结SHA恢复为逐字节相同内容；模型、配方和包输入均未改动。[恢复收据](local/adapter_metadata_recovery.json)保留旧哈希与过程，后续批次通过 protected_fit.py 将新元数据限制在本轮local，写入边界已实测通过。

复跑入口是 local/run_batch.py，迭代用 --phase iterate --workers 2 --nfev 100，参考用 --phase reference --workers 2 --nfev 500。已有完整收据保留，阶段失败日志也保留；全新重跑时使用独立的任务输出目录与冻结输入副本。敏感性入口为 local/sensitivity.py --indices all，容量为 local/capacity.py，最终核验为 local/audit_final.py。所有读照片或固件的 Python 命令均须带 -I -B，计算进程 nice=15，数值库单线程，最多两个。

本轮只关闭有界计算机候选筛选，不验证新DAT、v3.10真实运行、相机显示、持久化、SD卡安装或自然场景最终观感。
