# GXR 电脑工作室 · UX 设计（studio-ux-r1）

状态：设计稿 + 可点击原型。**不含正式产品代码。**
配套：`prototype.html`（单文件，双击用浏览器打开；图片是占位色块）。

所有预览、相似度都是**电脑预测**，不是相机实拍结果。

---

## 0. 一页看懂

- 一个在电脑浏览器里用的小工具，配合改造过固件的理光 GXR。
- 只做四件事：**导入、裁切、配方（含 LUT 转配方）、导出**。另加一组电脑专用的曝光/曲线调整。
- 相机是主角。电脑上调好的配方，要能写回相机卡，在相机里用。
- 电脑独有的功能，界面上一律标明「仅电脑」，不让人误以为能写进相机。

---

## 1. 设计原则

1. **相机为主。** 能在相机上做的，电脑只做预览和备份。电脑独有的功能要标清楚。
2. **不让人思考。** 每个页面只有一个主按钮；按钮写结果（「导出」「存下来」），不写技术名词。
3. **功能少。** 顶部 3 个页面，大图右侧 4 个标签。没有的功能就不放。
4. **绝不动原件。** 卡上的文件只读。裁切、调整、配方都是「记在旁边的说明」，原图随时可还原。
5. **诚实。** 近似就写「近似」，预测就写「电脑预测」，没在相机上验证的功能写「还没验证」。

## 4. 关键流程

### 流程 A：第一次打开

1. 打开应用，弹出三张引导卡（可跳过）。
2. 没有照片 → 显示 3.1 空状态。
3. 插卡 → 自动导入（流程 B）。
4. 不需要注册、不需要选文件夹。

出错：启动时找不到上次的库目录 → 提示「找不到照片库，请选择存放的文件夹」，给「选择文件夹」和「新建」两个按钮。

### 流程 B：插卡导入

1. 插入读卡器，横幅「发现相机卡」出现，导入自动开始。
2. 逐张复制到本地库；DNG 和 JPG 按文件名（不含扩展名）配成一对。
3. 按拍摄时间（EXIF）分组；没有时间的放进「未知日期」。
4. 完成 → 横幅「导入完成，共 N 张。现在可以安全弹出卡了」。
5. 人点「安全弹出卡」→ 底部显示「已安全弹出，可以拔下来了」。

出错与处理：

- 导入中拔卡（系统已弹出）：横幅变红「导入被打断了：已导入 7 张，剩下 5 张没有导入。插回卡可以继续。」插回后只导入缺的。
- 某个文件读不出来：跳过，计入「读不出来的 N 张」，不中断其他文件。
- 本地磁盘空间不够：暂停导入，提示「电脑空间不够，导入已暂停。清理后可以继续」。
- 卡上没有新照片：「这张卡上的照片都导入过了」。

### 流程 C：裁切

1. 大图 → 「裁切」标签。
2. 点比例（如 XPan 65:24）→ 画面上出现裁切框。
3. 拉直滑块调整角度，画面跟着转。
4. 「完成」→ 记下（原图不动）。
5. 想回去 → 「还原裁切」或大图底部「还原原图」。

### 流程 D：套配方并微调

1. 大图 → 「配方」标签 → 点一个底子（如 05 富士 CC）。
2. 预览立刻变成那个风格，标「电脑预测」。
3. 拖「对比」「高光」等滑块（每项 −9 到 +9，0 是原样）。预览实时变。
4. 满意 → 「存为我的配方」，起个名字。
5. 一个底子的微调不影响别的底子（和相机一样）。

出错：调到相机当前不认的数值（如对比 +7）→ 滑块能拉，旁边提示「相机目前只认 ±5，写入时会自动变成 +5」。

### 流程 E：导入 LUT 转成相机配方

1. 「配方」标签 →「导入调色文件（.cube）」，或「配方」页面的同名按钮。
2. 把 .cube 拖进来。预览显示「原图 / 加 LUT 后」切换（占位示意）。
3. 点「做成相机配方」。电脑比较 8 个底子，列出最接近的 3 个和百分比（电脑预测）。
4. 选一个底子 → 看差别说明 → 「存为我的配方」，给名字。
5. 存下后可以在「相机」页写回卡。

出错：

- 不是 .cube 文件：「这个文件看不懂。请选 .cube 格式的调色文件。」
- 1D LUT 或尺寸不支持：「这种调色文件暂时不支持。试试 3D 的 .cube。」
- 相似度 < 90%：红色标签「差别明显，先看看效果」，不阻止保存。

### 流程 F：导出

1. 大图「导出」标签 → 「导出这一张…」；或图库多选 →「导出选中的」。
2. 选范围、尺寸、质量、文件夹。
3. 「开始导出」→ 进度条 → 完成提示「导出完成：N 张」，有「打开文件夹」。

出错：

- 目标文件夹没有写入权限：「存到这个文件夹不行，请换一个文件夹。」
- 导出中断：已完成的保留，未完成的可以「继续导出」。
- 同名文件：自动加 `-2`、`-3`，不覆盖。

### 流程 G：把配方写回相机卡

这是唯一会改动卡的功能，流程最长，风险提示最多。

1. 「相机」页 → 「发到相机」。
2. 第 1 步：选一个「我的配方」。
3. 第 2 步：看清楚将写什么。相机不认的项会列出来，不会写入。卡上的原配方文件**先备份到电脑**，再写。
4. 第 3 步：勾选风险确认。
5. 点「备份并写入、校验」。写入后**回读校验**：一致 → 「写入成功，请先安全弹出，再放回相机，关机再开机才生效」；不一致 → 「写入没通过，卡上原文件已保留。」
6. 不论成败，备份文件都保留在电脑上。

前置条件与禁用原因（按钮旁必须写出原因）：

- 卡未插入 → 「先把相机的存储卡插到电脑上」
- 导入未完成 → 「等导入完成再写，免得两边同时读写」
- 未勾选风险 → 「请先勾选上面的风险确认」
- 没有我的配方 → 「先在电脑上调好一个配方，再来写回」

状态提示：功能在相机上实测前，页面顶部常驻一条「还没在相机上实测」黄条。实测通过后，黄条改为「已在相机上验证（版本 X）」。

## 8. 新手引导

目标：一分钟内知道三件事——**插卡会自动导入、点照片能裁和换风格、导出就是 JPEG**。

- **第一次打开：三张卡**（可跳过，之后可以在 `?` 里重看）
  1. 「插上卡，照片自动进来」——卡上的文件一个都不会改。
  2. 「点一张，裁一裁、换个风格」——裁切可以还原；风格是可以再微调的。
  3. 「调好了，导出 JPEG」——想带回相机，去「相机」页。
- **标签第一次出现时**：一句小字提示，右上角有 ✕，关掉就不再出现。例：「配方：相机里的风格，你可以在上面微调。」
- **专业词第一次出现时**：括号解释。底子、LUT、Cont、Satu 都是。
- **不做**：视频教程、长文档式的分步向导、强制完成的新手流程。
- **风险一次性确认**：只在第一次写回相机前出现。

## 9. 数据与安全（设计约束，工程必须遵守）

1. **卡只读。** 导入是复制到电脑的库；对卡的写入只有「发到相机」一个入口。
2. **复制后校验。** 导入完成前，比对文件大小和哈希，不一致的标为「读不出来」。
3. **原件不动。** 裁切、调整、配方、微调都存在旁边的说明文件里（每张照片一份），不写进 DNG/JPG。
4. **写回先备份。** 写入前把卡上现有的配方文件复制到电脑的备份文件夹；写入后回读校验；不通过就保留卡上原文件。
5. **写回入口受保护。** 必须：卡已插入、导入已完成、风险已勾选、已选配方。缺一项，按钮禁用并写明原因。
6. **未验证功能标黄。** 在相机上实测前，写回功能顶部常驻黄条。
7. **相似度标「电脑预测」。** 不显示「相似度 91%」而不带预测字样。

## 10. 待决问题（需要主人或工程确认，不影响原型）

1. **旋钮范围。** 相机指南写：对比、高光、阴影、饱和度目前只认 ±5；新版本计划 ±9。界面按 ±9 显示，写回时按相机版本截断——是否同意？
2. **「整体强度」(Amount 0–150%)** 的含义要确认：是否就是配方强度？相机里有没有对应项？原型按「100% = 原样」处理。
3. **仅电脑的项。** 褪色、冷暖、品绿、分离色调、黑白滤镜目前相机没有。界面保留并标「仅电脑」，是否接受？
4. **相似度阈值。** 相机实测（82–84%）低于电脑预测（90% 以上）。阈值（95 / 90）是否要整体下调？标签文字是否要改成更保守的说法？
5. **我的配方的数量。** 相机里 MyRec 有几格？电脑端「无限」但写回时要选格位，格位不够怎么办（覆盖？提示？）。
6. **黑白 03 隐藏哪些项。** 指南只说「饱和度不适用于 03」。原型按「饱和、冷暖、品绿、分离色调隐藏」处理，需确认。
7. **XPan 65:24 的裁切位置。** 默认居中还是保留原图的水平中线？
8. **卡上的文件结构。** DCIM 路径、DNG/JPG 配对规则（同名同号）需要用真实卡确认。原型假设「同名不同扩展名即为一对」。
9. **裁切框拖动**（位置调整）原型未做，建议一期加入。
10. **写回的备份位置**和保留时长，请确认。
11. **「导出」是否需要水印或文件名模板**（原型只给「原名 + _gxr」）。

## 11. 原型覆盖范围

`prototype.html` 能走通：

- 首次引导 → 空库 → 「模拟：插卡」→ 导入横幅 → 导入完成（含 1 张读不出来）→ 安全弹出。
- 图库：按日期筛选、角标（DNG+JPG / 只有 JPG / 只有 DNG）、多选、导出选中的。
- 大图：裁切（比例、拉直、还原）、配方（8 个底子、微调、整体强度、黑白隐藏规则、全部归零的两步确认、存为我的配方）、调整（曝光、对比、高光、阴影、白平衡、曲线拖动）、导出（范围、尺寸、质量、进度）。
- 导入 .cube → 做成相机配方（相似度、标签、差别说明、存为我的配方）。
- 相机页：卡状态、选配方、风险勾选、写回（演示，不真的写卡）。
- 快捷键：← → Space C R A E ⌘Z ? Esc。

原型不做：真实文件读写、真实 LUT 计算、拖动裁切框位置、真实导出文件。
