每个 `<单元>-<配方>.csv` 给出该组合的全部旋钮档位；`steps.csv` 合并这 24 张表。03 只有六个黑白旋钮，其余配方有九个彩色旋钮。

普通旋钮有 19 档，`dose` 是传给 C/Python 的有符号 Q12 剂量，0 为原配方。`amount` 有 16 档，`dose` 和 `level` 都是百分数，100 为原配方，0 为该单元原厂 04。它不使用 ±9，也不套用向两端增大的步长规则。

`adjacent_min_median_de00` 来自主机图表，不是相机屏幕测量。负档按从 0 向负端计算，正档按从 0 向正端计算。Amount 按 0% 向 150% 计算。小于 1.0 的值未通过本轮可见性门槛；空值表示该方向的起点。

`alternatives.csv` 给出 Warmth/Tint 的 T1 实现和黑白 Tone 的矩阵偏置实现。主表中的 Warmth/Tint、Tone 使用矩阵行和。偏置单位以及黑白色度通路尚未上机验证，不能把替代表当作已校准参数。

Q12 剂量在每一侧按凸序列增长。离线校准同时尝试增加相邻 ΔE00；有限色阶、裁剪和系数上限会使部分档位未达标，详见 `../REPORT.md` 和 `../local/calibration_failures.json`。这些表是研究候选，未接入引擎。
